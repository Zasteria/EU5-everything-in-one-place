# `cmf_dev_beta` — история

Вынесено из брифинга мода 10-12.

**С +beta5 (10-03) источник — CMF 2.5.0 из мастерской**, порт самих авторов на
1.4. Последние CMF Dev и CMF под 1.3 были побайтово одним модом, так что 2.5.0 — это
то, чем станет CMF Dev, когда авторы его обновят. Замер: из 208 ванильных типов
окон, которые CMF держит у себя, 200 совпадают с игрой 10-01, остальные 8 —
крючки CMF (лобби, кнопки в меню паузы, полоса уведомлений). Наши правки
+beta1..4 (75 типов беты, лобби беты, `use_global_input_instance`) авторы
сделали сами, они убраны. Горячую клавишу меню CMF автор вернул: профиль ввода
`default.profile` с `cmm_open_menu` (заменяет профиль игры целиком; профиля игры
в `reference/` нет, сверить не с чем).

**+beta6 (10-05): нижняя панель быстрых кнопок не держит место под скрытую
кнопку.** Ряд кнопок — `hbox` с datamodel без `ignoreinvisible`, и кнопка, чей
скриптовый интерфейс скрыт («Пересчитать» CM при закрытой карте), стояла пустым
квадратом 34 px, который не нажать (его скриншот 10-05). Верхняя панель —
вкладки, у неё этого нет.

## +beta8–11 (10-12), из брифинга 10-13

**+beta8–11 (10-12): номер места в упорядоченном списке**, его просьба «как в
мод-листе игры». Номер — место строки среди показанных: карта
`cmf_beta_list_place` на стране (ключ — флаг строки), её пишет
`cmf_beta_list_renumber = { setting }` после каждой перестановки; мод, который
прячет строки, зовёт его сам (автоматика совета — в `bag_asp_rebuild`). Ввод:
консоль (+beta8/9) не дошла; путь стрелок (+beta10: у Enter один обработчик,
`TriggerAnimation('cmf_beta_place_go')`, состояние зовёт `CMM_MarkListPosition_<i>`,
`CMF_BETA_MarkListPlace_<N>` — действие 51 — и `CMMExecuteListItemSettingChanged`)
**строку переносит** (10-12). `PdxClearEditBoxText` поле не чистит, поэтому
+beta11 как `mods_gui.gui`: номер — кнопка, щелчок открывает поле
(`GetVariableSystem` `cmf_beta_edit_place_<строка>`), Enter закрывает.
