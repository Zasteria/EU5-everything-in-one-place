# Как выложить мод в мастерскую

Написано, когда `glorpui_hints` дошёл до одиннадцати языков и его стало не
стыдно выкладывать. Ничего из этого нельзя проверить из сессии — Steam здесь
нет, — поэтому каждый пункт помечен: **проверено** значит, что это следует из
файлов в этом репозитории или из того, что уже работает; **со стороны** значит,
что это из вики и форума и хочет твоего подтверждения.

## Что вообще уходит в мастерскую

**Проверено.** Папка мода, и только те подпапки, которые монтирует игра:
`.metadata`, `in_game`, `main_menu`, `loading_screen`, `jomini`, `gfx`, `sound`,
`music`. Всё остальное в `mods/<мод>/` — `tools/`, `README.md`, `workshop/`,
`translations/` — наше и никуда не едет.

**Ничего паковать не надо.** `mods.bat` → **2** → мод → **«поставить в игру»**
уже делает ровно эту выборку и кладёт результат в

```
Documents\Paradox Interactive\Europa Universalis V\mod\<имя мода>\
```

Эта папка и есть то, что загружается. То есть порядок такой: собрать (пункт 2),
поставить в игру (пункт 4), проверить в игре, загрузить.

## Перед первой загрузкой

```
python3 tools/publish.py                 все моды
python3 tools/publish.py glorpui_hints   один, и текст, который надо вставить
```

Он проверяет то, на что никто не ругается и что видно только потом:

| | |
| --- | --- |
| `.metadata/metadata.json` | без него лаунчер мод не покажет вообще |
| `version` | лаунчер читает `x.y` или `x.y.z`; версию, которую он не прочитал, он не считает новее |
| `id` | **после публикации не менять никогда** — у подписчика окажется два мода сразу, оба смонтированы |
| `tags` | у мастерской свой список, чужой тег она молча выбрасывает, и мод оказывается вообще без категории |
| `.metadata/thumbnail.png` | это картинка страницы в мастерской, а не только иконка в лаунчере; PNG, 512×512, меньше 1 МБ |
| BOM у `.yml` | без него текст в игре превращается в кашу |

**Теги — это тот случай, который уже сработал.** Четыре наших мода лежали с
тегом `Localization`, которого у EU5 нет; нужный называется `Translation`, а
`Economy` на самом деле `Trade and Economics`. Полный список — в
`WORKSHOP_TAGS` в [`../tools/publish.py`](../tools/publish.py), считан с
фильтра самой мастерской 2026-08-27.

**Картинки нет ни у одного мода, кроме `glorpui_hints`.** Если будешь
выкладывать что-то ещё — `mods/glorpui_hints/tools/make_thumbnail.py` рисует
такую.

## Сама загрузка — она в игре, и найти её нельзя

**Проверено 2026-08-27.** Кнопка есть, она встроенная, и добраться до неё можно
только зная, куда смотреть — в лаунчере её не видно, в вики её нет, и час
поисков ушёл именно на это.

**Путь:** «Модификации и дополнения» → строка **«Выбранные модификации: N/M»**
→ маленькая **иконка песочницы** справа в этой строке (рядом с шестерёнкой),
не в шапке и не внизу. Откроется окно **Mod Tools** с двумя вкладками:
**Create mod** и **Uploaded mods**.

Это же описано в дневнике разработчиков
[Tinto Talks 85 (22 октября), Modding](https://forum.paradoxplaza.com/forum/developer-diary/tinto-talks-85-22nd-of-october-modding.1864004/)
— одной строкой, посреди текста про события и ситуации: *«navigate into the
Mods & DLCs Menu in the top right corner and then open the Mod Tools view by
clicking on the sandbox icon next to Selected Mods»*. Дневник целиком про то,
как мод **писать**; про то, как его выложить, там только эта фраза и кнопка
**Upload New Mod** на скриншоте.

**Значит сторонний PDX Workshop Manager не нужен.** Он остаётся запасным путём
(конфиг для него пишет `tools/publish.py`, из меню этот пункт убран 10-03), но первым идти надо в
игру.

### Что вписывать

Форма Create mod повторяет `metadata.json`. Заполняй **ровно теми же
значениями**, что уже лежат в файле, — тогда неважно, читает тул файл или
перезаписывает его из формы. Для `glorpui_hints`:

| поле | значение |
| --- | --- |
| Name | `Societal Value Hints` (до 1.2.7 — «Glorp UI - Societal Value Hints», переименован 10-04: Glorp больше не нужен) |
| ID | `bag.glorpui_hints` |
| Path | `glorpui_hints` — поле идёт после подписи `mod/`, то есть это имя папки, а не полный путь |
| Version | из `metadata.json` (1.2.7 на 10-04) |
| Supported game version | `1.4.*` |
| Description | короткое, из `short_description`; длинное вставляется потом на странице |
| Tags | User Interface, Fixes, Translation |

`python3 tools/publish.py glorpui_hints` печатает всё это же, чтобы не лазить в
json.

Галочки Tags в этом окне — **и есть настоящий словарь тегов**, тот самый, из-за
которого четыре наших мода лежали с несуществующим `Localization`. Версии игры
(`1.3`) среди галочек нет, так что этот тег просто не проставится — ничего
страшного.

Потом — **Upload New Mod**. Загружается папка из `Documents\...\mod\`, ту
самую, что кладёт пункт 4.

### Две вещи, которые надо проверить сразу после

- **На форуме есть баг-репорты, что Mod Tools создаёт пустой мод** — без
  названия, без описания и без файлов. Открой страницу мода в мастерской и
  посмотри, что там вообще что-то есть. Если пусто — второй путь, PDX Workshop
  Manager, и конфиг для него уже готов.
- **`metadata.json` после загрузки.** В форме нет поля для зависимостей, а у нас
  там объявлен CMF. Если тул перезаписал файл из формы, блок
  `relationships` мог пропасть: посмотри
  `Documents\...\mod\glorpui_hints\.metadata\metadata.json`. Пропал —
  пункт 4 положит его обратно, и загрузи ещё раз.

## Что делает страница, а не файлы

**Со стороны.** Часть вещей живёт только на странице мода в мастерской и в
`metadata.json` не задаётся:

- **описание — своё на каждый язык.** На странице мода есть переключатель
  языка, и у каждого своё поле; язык без описания получает описание по
  умолчанию. Так что мод на одиннадцати языках хочет одиннадцать описаний.

  Они лежат в `mods/<мод>/workshop/`, по файлу на язык, в BBCode: открываешь
  блокнотом, копируешь целиком, вставляешь в поле того же языка. BBCode —
  родная разметка Steam, `[h1]`, `[b]`, `[list]`, `[hr]` он разберёт сам,
  конвертировать нечего.

  **Что в описании должно быть, и чего в нём быть не должно.** Только то, ради
  чего мод сделан, что он даёт, от чего зависит и на каких языках работает.
  **Не** сколько ключей заменено, не сколько строк в файлах, не история того,
  что было сломано и как чинилось — это всё живёт в `docs/` и на странице мода
  никому не нужно. Первая версия описания была вчетверо длиннее и состояла
  ровно из этого; владелец её забраковал, и он был прав.

  **И про нейросеть — обязательно, в каждом языке.** Последней строкой, курсивом:
  мод целиком, включая описание, сделан с её помощью, протестирован насколько
  было возможно, результат владельца устроил. Это не оговорка мелким шрифтом, а
  то, что человек имеет право знать до подписки.

  Потолок одного поля — 8000 символов, Steam при переполнении не отказывает, а
  обрезает. `python3 tools/publish.py <мод>` печатает длину каждого файла,
  ругается на превышение и на язык, для которого описания нет;

- **зависимости** — «Add/Remove Required Items» на странице. Для
  `glorpui_hints` с 1.2.7 это только Community Mod Framework: Glorp UI из
  Required Items **убрать**, мод работает без него. Без этого подписчик получит мод без того, на чём
  тот стоит, и увидит пустую подсказку;
- **видимость.** Выложи сначала скрытым или «только друзьям», подпишись сам,
  проверь в игре и только потом делай публичным. Мод в мастерской видно сразу
  всем, и первые впечатления не переписываются;
- **changelog** при обновлении.

## Обновление под бету игры — не в тот же предмет

**Проверено 10-04, его ценой.** У Steam нет веток мода под версию игры: что
залито в предмет, то и получают все подписчики. Он залил сборку под бету 1.4 в
основной `glorpui_hints`, и у всех на 1.3 мод сломался. Выход: **отдельный
предмет** — у нас основной остался на 1.4, версия 1.3 ушла новым предметом из
`mods/glorpui_hints_1_3` (свой id, имя с «(1.3)»), ссылка — комментарием.
Прежде чем обновлять предмет, сверь `supported_game_version` с тем, на чём
играют подписчики; бета — новый предмет, а не обновление.

**Описания вставляются как есть:** поле на странице само понимает BBCode
(`[h1]`, `[b]`, `[list]`); `.bbcode` — просто текст.

## После публикации

- **Локальную копию из `Documents\...\mod\` лучше убрать** (пункт 4, `у` +
  номер), когда подпишешься на свою же мастерскую: иначе один и тот же `id`
  приезжает с двух сторон.
- **Мод обновляется повторной загрузкой той же папки** под тем же workshop id.
  `id` в `metadata.json` при этом не меняется никогда, меняется `version`.
- **`tools/mods.py` теперь увидит твой мод как чужой** — он читает всю твою
  подписку. Это нормально: пункт 3 умеет переносить мод между `reference/` и
  `playset/`, и наш собственный мод там просто ещё одна строка.

## Что стоит сказать в первый раз

`glorpui_hints` переопределяет тот же шаблон подсказки, что и Glorp UI, и с
ним должен стоять ниже. Это написано в описании прямо, потому что любой другой мод, трогающий те же шаблоны, с ним
подерётся, и лучше, чтобы человек узнал об этом на странице, а не в игре.

Про соседа по нише — `Glorp UI small fix` (3784988919) — врать не надо и
ругать его не надо: он переводит те же 759 ключей на десять языков и больше
ничего не делает. Кто встал позже, тот и выиграл эти ключи; остальное у нас
своё. Если человек поставит оба, поломки не будет.

## Putting `glorpui_hints` out, in order

Moved here from [`NEXT_SESSION.md`](NEXT_SESSION.md), which only points at
it now. The steps are the same for any mod; the mod-specific parts are the
two Required Items in step 5.

`python3 tools/publish.py glorpui_hints` says `ok`; everything is ready.

1. merge the branch, then `mods.bat → 2` → the mod → «поставить в игру»;
2. load once and check the list above;
3. in game: mods screen → «Выбранные модификации» row → **sandbox icon** → Mod
   Tools → *Create mod*, filled from `metadata.json` (the table is in
   [`WORKSHOP.md`](WORKSHOP.md)) → **Upload New Mod**;
4. check the page is not empty and that `relationships` survived in
   `.metadata/metadata.json` — both are known ways this tool has misbehaved. The
   fallback is [PDX Workshop Manager](https://github.com/kaiser-chris/pdx-workshop-manager);
   `tools/publish.py` writes its config (a session runs it);
5. on the workshop page, by hand: **Glorp UI** and **Community Mod Framework**
   as Required Items, and **hidden first**.
