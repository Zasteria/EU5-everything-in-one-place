# Патч 1.4.7, 2026-11-03 (Steam build 26377361): что он сломал в модах

`eu5.exe` называет себя «1.4.7 Río Salado»; до него 1.4.6 (26300913, 31.10).
Сверка по файлам: `reference/` до (`9aa8505a`) и после — 66 файлов (6 новых,
60 изменённых, удалённых нет). **Функции движка не сверены**: дампы API от 10-13.

## Что поменял патч

- **Освобождение от пошлин силой**: казус белли `cb_tariff_dispute`, цель войны
  `enforce_tariff_exemption`, пункт мира `demand_tariff_exemption`, отношение
  `enforced_tariff_exemption` (отменить нельзя, пока идёт перемирие), триггер
  `tariffs_paid_to`.
- **Персонаж принимает религию страны**: взаимодействие `adapt_religion` (триггер
  `can_adopt_religion_of_country`), мнение `opinion_ruler_religion`.
- **Наём советника**: шанс евнуха — script value `hire_advisor_eunuch_chance`,
  `hire_advisor.txt` похудел на 90 строк.
- Казнь персонажа — не претендента кризиса; подсказки разнородных войск
  (`COMBINED_ARMS_*`); Ирландия (`yearly_flavor_ire_pulse`), Гранада в «Битве за пролив».
- **Окно района**: права города в боковой панели вынесены в свой слот
  (`location_card_town_rights_vertical_slot`, шаблон `location_card_town_rights_vertical`
  33×33); кнопки рынка 90 → 70, населения 120 → 100.
- Русские файлы игры патч не трогал: 47 новых ключей вышли без русского.
