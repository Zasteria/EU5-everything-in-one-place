# Сколько стоит HRE Manager — по его файлам

**Его вопрос, 2026-10-12:** HRE Manager 1.1.0 (Workshop 3705462070) «знатно
тормозит игру», хотя на вид это просто интерфейс. Он спросил, чем мод тормозит, и
можно ли наткнуться на то же самое в наших модах.

**Короткий ответ по файлам: пока вкладка закрыта, мод не делает ничего.** В игре
это не мерили.

## Чего в нём нет

- Нет `scripted_widgets`, событий, `on_action`, цикла анимаций — то есть нет
  ничего, что живёт каждый кадр или каждый день.
- Все десять `GetScriptedGui` стоят в `onclick` или в `on_finish` как
  `.Execute`. Ни один не стоит в `visible` или `enabled`.
- Его вкладка стоит за ванильным гейтом `organization_custom_content_visible`
  (`common.gui:609`), и гейт стоит на корне.
- Все функции движка, которые зовут его `.gui`, есть в дампе беты.

## Где цена есть

1. **Открытая вкладка «Manager», каждый кадр, на каждую строку.**
   `Country.GetQuickDiplomaticActions` — весь список дипдействий с их
   условиями — плюс четыре `GetTheirOpinionPlayer`. Это идёт по всем членам
   Империи сразу. Ваниль зовёт то же на карточку страны, но только для стран,
   видимых на экране (`diplomacy_macrobuilder_lateralview.gui:1014`, `:2371`).
2. **Щелчок по сортировке.** `ordered_country_in_diplomatic_range` обходит
   каждую страну в дипдальности. Сортировка по провинциям для каждой из этих
   стран ещё и считает `every_owned_location` (`hrm_owned_location_count`). Такое
   даёт рывок на щелчке, а не постоянные тормоза.
3. **`trigger_on_create`** собирает тот же список при создании панели, а по
   [`../pitfalls/windows.md`](../pitfalls/windows.md) — ещё и на загрузке
   сохранения.

## Не цена, но заметно

Мод целиком заменяет `panels/organization/hre.gui` своей копией времён 1.1:
779 строк против 3 948 в бете, 82 `blockoverride` против 341. Отсюда по файлам
следует, что под ним в окне Империи пропадает ванильное содержимое, сделанное
позже: `GetImperialCircleItems`, `GetHreHeaderActions`, списки голосования
сейма. В игре это не смотрели.

## Если тормоза есть при закрытом окне

Файлы этого не объясняют. В тот же день в плейсет добавлено ещё несколько модов.
Сама игра замедляется за час игры из-за утечки виджетов
([`widget_leak.md`](widget_leak.md)), и сравнивать надо только после выхода в
главное меню.
