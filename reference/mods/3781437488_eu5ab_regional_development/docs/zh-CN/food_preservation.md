# 粮仓保鲜公式与适用边界

[English](../en/food_preservation.md) | [食物设施规则](automation_rules.md#食物设施)

本页说明 Mod 计算粮仓减损收益的方法；扩容需求、收益门槛和同省施工限制见[粮仓与风车](automation_rules.md#粮仓与风车)。实现入口为 [food_infrastructure.py](../../src/eu5autobuild/food_infrastructure.py)。

## 当前计算公式

保鲜总量非负时，按以下顺序计算预计月腐损：

```text
B = max(0, 省会 local_food_decay + 省会所属国家 global_food_decay)
E = 全省各地点实际 local_food_preservation_efficiency_modifier 之和
F = max(0, 当前省库存)
r = trunc5(B / (1 + E))
D(E) = trunc5(F × r)
预计月节粮 = max(0, D(E) − D(E + 0.05))
```

`trunc5` 表示截断到五位小数，`D` 是损失的正数大小。先计算腐损率，再乘库存；两步分别保留游戏定点数精度。

## 适用规则

- 省会与非省会粮仓采用同一全省收益口径，保鲜总量包含全省各地点的修正。
- 城市、乡村粮仓每新增一级统一粗估增加 `0.05` 保鲜效率。计算固定当前库存、价格及其他修正，新增容量不计作已有食物。
- 在此模型中，100% 保鲜使正的基础腐损约减半；超过 100% 仍有递减的减损收益。
- 基础腐损不为正或保鲜总量为负时，Mod 不计减损收益，储粮扩容需求仍单独判断。
- 粮仓间接收益为预计月节粮乘当前食物价格，计入项目收益比较；它不作为税收收入。

## 仍待验证

- 引擎在负保鲜、非正基础腐损和极端高保鲜条件下的实际行为。
- 受控建造前后的实际边际减损，与固定 `+0.05` 预测的差异。
- 自动开工、扣款、取消、存读档和竣工的完整生命周期，见[游戏内验证指南](runtime_validation.md)。
