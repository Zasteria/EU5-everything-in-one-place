# 价格与市场补建

[English](../en/market_construction.md) | [自动建造规则](automation_rules.md) | [产能预估](production_forecast.md)

本页说明价格、配方和补建的计算规则。普通建筑与原产均使用候选地点所属市场的价格。

## 价格与排序

令 `p` 为现价占基础价的百分比，`L` 为最低价，`H` 为高价参考：

| 条件 | 处理 |
| --- | --- |
| `p ≤ L` | 暂停新增 |
| `L < p < 100`，且 `L < 100` | 低价系数为 `(p − L) / (100 − L)` |
| 通过最低价且 `p ≥ 100` | 低价系数为 1 |
| `L ≥ 100` | 只执行最低价门槛 |
| `H > 100` | 高价规划奖励为 `140 × clamp((p − 100) / (H − 100), 0, 1)` |
| `H ≤ 100` | 仅在 `p > 100` 时给予完整 140 分 |

高价参考是奖励封顶位置，不能绕过最低价。多产出建筑按所选配方的「产量 × 基础价」加权；触底产出贡献为零，全部贡献为零才暂停。缺少有效市场或价格时，商品生产项目暂停；真正无商品产出的设施保持价格中性。

低价系数对非负分做乘法，对负分做除法，保证降权方向，并保留最小正精度及数值下限。规划评分和最终利润排序各应用一次；140 分只进入规划评分，最终利润由原版收益体现价格。真实短缺另行加分。

启用的粮食紧急保障豁免相关产粮项目的最低价和低价衰减，仍需有效数据及其他建造条件。建材、军需的收益豁免不包含价格豁免。风车只使用当地实际作物价格；粮仓与灌溉采用专门需求规则。

## 配方与产业偏好

扩建优先读取实际生产方式。新建或替换按可用配方估算，优先选择供给可行且经济性较好的配方；平分时保持声明顺序，没有可行配方时保留估算用于缺料诊断。实际方式即使缺料或收益较低，也不会被估算覆盖。Mod 不切换或锁定方式。

上游来源须能确定产出目标商品：实际方式产出该商品，或某生产槽位的全部可用替代方式都产出该商品。估算选中了工具配方，或原版预计利润为正，都不能单独证明建成后一定生产工具。

规划经济项使用原版预计利润与造价之比，风车和粮仓补计间接收益。城市特权、鼓励产业按直接产出的基价价值占比提供偏好；它们不等于真实利润，最终利润排序不重复追加这些规划分。

## 补建范围

- 普通阶段先执行；市场补建只比较本轮已检查、本国拥有、同市场且受模板管理的地点。
- 风味模板可补建未列为重点的产业，但明确禁用项和自定义优先级 0 仍有效。
- 上游补建独立检查短缺，无需先有下游候选失败；满员但缺料的工厂也可触发。
- 已有工程但仍有施工名额的地点可以参与。上游补建不消耗普通建筑有限补位的额外尝试次数。

两条补建路径、普通生产项目与原产共享本国同市场同商品的产出和未来投入。有效需求为当前需求加尚未计入市场的已确认运营投入；两者均为零时不作市场补建。额度为有效需求缺口加有效需求的 10%，随待投产产能增加而降低排序，达到额度后暂停。未知参考、竣工保护和混合工程归属见[产能预估](production_forecast.md)。

## 检查与开工时点

普通建筑和原产保留检查阶段取得的价格、劳动力、费用及容量；开工前核对归属、现金、其他预留与可用名额。普通建筑费用来自原版报价，原产费用仍为估算。市场商品快照在当月首次读取后复用；未使用缓存的商品辅助读取保留实时取价。

普通建筑和原产在同次脚本执行中依次下达原生命令并确认结果。实际成功后按逐项金库差额计入年度支出；失败归还资金、材料、产出和名额预留，同月跳过该候选。最后一项可超年度预算，随后停止剩余开工。

地点名额由普通建筑和原产共用。原版总占用包含手动、阶层和其他民用工程；未完工的建造部门不提前提供名额。同地点重复扩建各有独立工程记录。后续只更新受本轮项目影响的供给和预留，不重做整套初筛。
