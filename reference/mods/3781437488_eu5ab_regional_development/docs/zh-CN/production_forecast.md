# 普通建筑产能预估

[English](../en/production_forecast.md) | [价格与市场补建](market_construction.md) | [游戏内验证指南](runtime_validation.md)

普通生产建筑与原产按国家、市场和商品共享待投产供给，用于控制后续开工。预留不改变游戏实际供需，也不取消已有工程。

## 需求、额度与排序

令 `D` 为当前月需求，`F` 为已确认但尚未进入市场需求的新增运营投入，`S` 为当前月供给，`P` 为待投产月产出：

```text
有效需求 D_eff = D + F
额度 B = max(D_eff − S, 0) + 0.10 × D_eff
```

| 待投产产出 | 处理 |
| --- | --- |
| `P = 0` | 系数为 1，仍检查其他条件 |
| `0 < P < B` | 系数为 `1 − (P/B)²`，保留最小正精度 |
| `P > 0` 且 `P ≥ B` | 暂停新增；最后一个不可拆分等级可以跨过额度 |

非负分乘系数，负分除以系数并保留数值下限。规划和最终利润排序各应用一次。多产出按正的净参考数量 × 基础价加权；任一正产出达到额度即阻止项目，互斥生产方式不累加为同时产出。

启用的粮食紧急保障豁免这条曲线和额度，但仍登记产能。建材、军需的收益豁免不包含产能豁免。未来投入不绕过价格、收益、原料、劳动力、预算和施工条件。

## 只登记确认开工的项目

每次 Mod 命令最多登记所请求的一层，须由命令前后的精确建筑实例变化确认。后续手动追加不扩大登记数量，刷新与读档不接管原生队列或遍历全国产能。

同类型手动工程和 Mod 工程无法逐项辨认时，采用手动优先竣工、Mod 优先取消的保守归属；符合条件的 Mod 记录按登记先后竣工。两次观察之间取消又重建、物理总量不变时，仍可能无法识别。

## 参考产量

每个生产槽位须有唯一、已识别的当前方法；缺失、冲突或未识别方法记为未知。参考数量采用：

```text
静态配方数量 × 参考效率 × Mod 确认新增等级
```

扩建沿用原建筑效率，只估算新增部分。新建和升级优先参考同地点、本国拥有、非阶层的已建目标类型；否则只在本国同市场查找一个同类型参考地点。没有可用参考则保持未知，不默认假定效率，也不分摊地点总产量。

升级在开工前固定目标效率、前身产量及各商品正的替换差额。施工期间前身实际消失时，只补回一次此前抵扣，避免市场供给下降后继续扣旧产量。

未知参考仍可通过其他条件开工，但不产生虚构的产出或投入预留，因此首批施工可能多开。竣工后的保护期内首次读到有效方法与效率时可以建立参考，不延长截止时间。有效零与未知分别处理。

## 施工与投产

已知施工预留保留到竣工、取消或归属失效，不因人口预测期限到达而提前清除。

竣工后，剩余预留为净参考数量 × 新增岗位空缺比例。扩建排除原有岗位，后续手动增加的等级不扩大记录。满员即释放，即使工厂缺料或停业；后续用工下降也不重新挂回。这是就业近似，不是实际产量测量。

| 竣工时状态 | 投产保护与地点 × 建筑类型冷却 |
| --- | --- |
| 记录期限为 0 | 撤销施工预留，不增加额外保护或冷却 |
| 期限非零、参考已知 | 从竣工日开始使用已记录期限 |
| 期限非零、参考未知 | 从竣工日兜底 3 个月，不叠加配置期限；有效读取后才建立商品预留 |

满员可提前释放预留，冷却保留原截止时间。分批竣工分别计时；重新读取、读档和后续竣工均不续期。到期仍未满员也删除对应记录，不能凭物理等级重新登记。月底日期按目标月份的实际天数截断。

## 状态变化与维护

配方变化按保存效率更新商品，清除旧预留；每次刷新同一建筑只检查一次当前方法，各项目仍保留独立效率、抵扣、释放状态和期限。仅遍历实际涉及的商品。

市场转移时将有效预留移至当前市场；易主、取消或实例失效时删除对应记录。存在登记项目时，每日维护独立于月度扫描和新增开工开关；最后一条记录消失后停止。读档按保存数量恢复索引及维护，不增加项目或延长期限。

旧生产采样字段不转换成新项目；无法证明由 Mod 开工的旧工程不接管。当前预测不再依赖生产采样动画、回执或重试，但报价和容量仍需各自的游戏界面读取。

风车、粮仓和灌溉保留[专门规则](automation_rules.md#食物设施)，不作为普通独立生产配方提前抵扣其间接收益。
