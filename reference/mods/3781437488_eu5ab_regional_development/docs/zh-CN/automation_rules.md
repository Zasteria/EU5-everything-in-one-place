# 自动建造规则

[English](../en/automation_rules.md) | [安装与上手](../../README.zh-CN.md)

## 模板与全国设置

模板决定哪些地点参与自动建造，以及各建筑的优先级。风味模板提供现成的发展方向；自定义模板可逐项调整，优先级为 0 时禁用该建筑。风味模板可以特别允许个别通用评分为 0 的建筑，复制为自定义模板时按 1 分启用。推荐分数见[建筑优先级](building_quality_priorities.md)。

调整优先级时，普通点击增减 0.1，Ctrl+点击为 0.5，Shift+点击为 1.0。模板可应用到地点、省份或地区；「清除策略」可解除地点分配。

预算、最低准备金、同时建造上限、决策策略和保护规则在 CMF 模组设置中调整，全国共用。

| 设置 | 实际作用 |
| --- | --- |
| 年度预算 | 每年首次结算时，按固定金额或全国月总收入的 4、6、8 倍核定。修改设置会重算额度，读档不会补回已用预算。 |
| 预算用完 | 普通建筑与原产扩建共用预算，按实际扣款记账。最后一个项目可以超出剩余预算，随后停止追加。 |
| 最低准备金 | 开工前检查预计费用、已安排项目的预留和剩余现金。实际费用可能变化，准备金并非绝对保证。 |
| 同时建造上限 | 设置的是基础 1 项之外的额外名额：0 表示最多 1 项，599 表示最多 600 项。普通建筑与原产共用。 |
| 地点施工限制 | 须有原版允许的空余施工名额，并结束地点冷却。每批调度结束后进入 3 个月冷却。 |

手动、阶层和其他 Mod 的工程仍占原版施工名额，但不会直接加入本 Mod 的项目计数。同类型工程混在一起时，归属可能无法精确区分，Mod 会保守保留已有计数。

## 每月怎样安排建造

1. **2～22 日**分批检查已应用且已启用模板的地点。普通月度检查最多详细评估 600 个地点，并轮换检查起点。
2. **最早 23 日**开始安排工程。必要的游戏读数尚未完成时，开工会延后。
3. 先处理已开启的粮食紧急保障，再按建造类型顺序选择项目。默认顺序为 **升级 → 普通扩建 → 原产扩建 → 新建**，可在设置中拖动调整。
4. 某项无法开工时继续尝试其他项目；仍有名额和检查额度时，可在本月继续补查。
5. 月底结束未执行的计划，次月重新检查。已开工工程和真实支出继续保留。

优先级只影响同一阶段、同一建造类型内的比较，不会越过类型顺序。检查期间取得的价格、费用等读数会用于后续安排，因此计划不一定反映开工当日的所有变化。

「建造报告」中的最后扫描日期记录实际检查日期；读档或结算不会刷新它。排行按所选策略列出项目，同一地点可以出现多项。

## 决策策略与性能设置

- **供需规划**：综合市场短缺、食物与建材需求、产业配套、本地原料和劳动力风险。模板优先级每点增加 50 规划分；普通扩建还按该建筑已建成等级，每级增加 1 分。
- **预测利润择优**：优先比较游戏预测的月净收益，并计入风车增产、粮仓减损等间接收益。模板优先级提供辅助加成，每点约 1%，最高约 10%。它比较已评估项目，不保证找到全国收益最高的工程。

「性能优化 → 高级设置」可调整每个地点、每种普通建造类型保留的候选数量，范围均为 3～30。数量越多，备选越充分，检查也可能更慢。

| 性能预设 | 规划候选数 | 利润候选数 |
| --- | ---: | ---: |
| 保守 | 5 | 15 |
| 平衡 | 4 | 12 |
| 效率优先 | 3 | 10 |

「失败后有限补位」默认关闭，下轮检查生效。当前类型的优先项目均未开工，且该地点尚无普通建筑成功开工时，继续尝试后续项目。每轮每地额外尝试最多 2 项（供需规划）或 5 项（预测利润择优），各普通建造类型共用次数；成功后停止补位，读档不恢复次数。

### 产业方向

城市特权会提高符合当地产业方向的项目优先级，最多增加 500 规划分；仅在特权所在地点生效。鼓励产业也最多增加 500 分，只适用于本国扶持地区内、直接生产相应商品的建筑，不惠及只消耗该商品的建筑或原产扩建。

多产出建筑按各商品的「产量 × 基础价」占比加分。两项偏好独立相加，仍须通过模板、价格、劳动力及其他开工条件；它们不会自动授予特权、改变生产方式或保证盈利。预测利润择优不会在最终利润上重复叠加规划分。

### 地点建筑容量

容量占用按实际就业折算：10 级建筑在 50% 用工时，约占 5 个满员等级。

| 满员等级占上限的比例 | 对新增建筑的影响 |
| --- | --- |
| 不超过 95% | 正常比较 |
| 95%～110% | 逐步降低优先级；100% 时约保留 2/3，105% 时约保留 1/3 |
| 达到或超过 110% | 暂停净增加占用的项目 |

真正拆旧一级、换新一级的升级不增加实体等级，仍可评估；只有升级关系、没有可替换旧建筑时不享有此例外。原产和不计入该上限的建筑按各自规则处理。粮食紧急保障也不能突破容量限制。

判断使用检查时的容量，不预先计入未完工工程的用工。最后一项获准工程完工后可能超过 110%，不会因此拆除或取消工程。

## 项目为什么没有开工

先查看「建造报告」，再对照以下条件：

| 条件 | 需要满足的要求 |
| --- | --- |
| 模板与游戏规则 | 模板允许，建筑已解锁，地点符合原版条件；特殊建筑还需开启相应设置。 |
| 施工与容量 | 有空余施工名额，冷却结束，建筑容量允许新增占用。 |
| 劳动力 | 开启保护时，普通建筑预测在设定期限内能否填满新增岗位，默认 12 个月，可设 0～240 个月。 |
| 原料 | 开启保护时，所需受保护工业原料的市场供给至少达到需求的 75%。 |
| 产出价格 | 达到或低于最低价时暂停；多产出建筑按价值占比计算，全部产出触底才暂停。 |
| 建材 | 考虑本轮已安排项目的材料需求，材料价格上限为基础价的 150%。 |
| 财务 | 年度预算尚有余额，现金能够覆盖预计费用、其他项目预留和最低准备金。 |
| 收益与设施需求 | 通过所选收益要求，以及灌溉、粮仓、风车各自的需求判断。 |

关闭劳动力保护后，不再预测新增岗位能否在期限内填满；当前合格空闲人口不足时降低优先级，不单凭缺工禁止开工。原产现有岗位满员的要求仍然保留。

最低价以下暂停，最低价与基础价之间逐步降权；高于基础价逐步增加偏好，到高价参考值后奖励封顶。**高价参考不是最高允许价格**。更多计算细节见[价格与市场补建](market_construction.md)。

### 原料保护与补建

扩建优先使用建筑当前的生产方式；新建或替换使用可行配方估算。Mod 不切换或锁定生产方式。

「短缺时自动补建上游」检查原料缺口，无需先有下游项目失败。「有空余建造名额时补建市场紧缺产业」在普通阶段之后，从本轮已检查、本国拥有、同市场且受模板管理的地点中选择。自定义模板的 0 分禁用仍有效；已有工程的地点只要还有名额，也可参与。

普通建筑与原产会考虑已经安排、尚未充分投产的产能，逐步减少同商品的追加建设，避免反复填补同一缺口。缺少可靠产能参考时无法作此抵扣，可能多安排项目；详见[产能预估](production_forecast.md)。

## 收益门槛与紧急保障

| 界面选项 | 开工要求 |
| --- | --- |
| 收入 | 预测月收入大于 0 |
| 利润 | 预测月利润大于 0 |
| 收入回报率 | 预测月收入至少为建造成本的 5% ÷ 12 |
| 利润回报率 | 预测月利润至少为建造成本的 5% ÷ 12 |

两种回报率都是**年化 5%**。收入没有扣除运营成本；预测值也不保证实际回本时间。无商品产出的公共基础设施不受普通生产建筑的收益门槛限制。

开启对应保障后，以下情况可豁免普通生产建筑的收益门槛：

| 情况 | 适用项目 | 优先处理 |
| --- | --- | --- |
| 食物预计耗尽，或储备不超过 25% | 对应产粮建筑 | 是，两种情况各有开关 |
| 核心建材供给不超过需求的 65% | 对应建材建筑 | 否 |
| 战时军需供给不超过需求的 65% | 对应军需建筑 | 否 |
| 上游原料供给不超过需求的 65%，且阻碍战略建筑 | 对应原料建筑 | 否 |

粮食紧急保障另可豁免相关产粮项目的最低价格和待投产额度限制。建材、军需豁免不包含这两项；预算、劳动力、容量及游戏条件仍适用。

## 食物设施

### 灌溉系统

满足以下任一条件才会考虑建造：

- 市场预计耗尽食物，或储备不超过容量的 25%。
- 市场储备不超过容量的 50%，且月食物收支为负。
- 地点人口达到人口容量的 90%。

灌溉增加本地食物产出和人口容量，不直接生产谷物商品，也不因谷物涨跌价而获得奖励或被拦截。高优先级不会绕过需求判断。目前不抵扣其他在建灌溉的预计增益，因此多处可能同时响应短缺。

### 粮仓与风车

城市粮仓和乡村粮仓都服务于**省份储粮**，可因下列任一理由建造：

- **扩容**：库存达到容量的 75%，容量不足居民 6 个月消费量，并且本地食物有盈余或包含市场往来后的净流入为正。
- **减损**：预计减少腐损的食物价值加上建筑运营净收益为正，且达到建造成本的年化 5%。

同省只安排一项在建或待开工粮仓，两类粮仓共用限制。省会和非省会的减损收益都按全省计算；每新增一级粗估增加 5 个百分点保鲜效率，使用当前库存和价格。保鲜超过 100% 仍有递减收益；基础腐损不为正或保鲜总量为负时不计减损收益，扩容仍单独判断。粮仓不作为产粮工程进入紧急队列。计算口径见[粮仓保鲜公式](food_preservation.md)。

风车要求当地实际产出小麦、稻米或小米，并且有市场食物需求、该作物短缺或价格高于高价参考值。最终还须有正的增量净收益；选择回报率模式时须达到年化 5%。收益按现有产出修正计算新增效果，并计入运营成本，粮食紧急保障也不会跳过此要求。

## 原产扩建

原产（RGO）独立评分，不使用普通建筑的收益指标。现有岗位必须满员，并符合模板、等级上限、价格、预算、准备金和施工条件。

| 劳动力保护 | 原产模式 | 新增岗位判断 |
| --- | --- | --- |
| 开启 | 宽松（默认） | 不预测未来用工 |
| 开启 | 考虑人口 | 预测期限默认 180 个月，可设 0～1200；0 只看当前可用人口 |
| 关闭 | 宽松 | 不预测；当前合格空闲人口不足时降低优先级 |

预测按当前转职速度计算，期限越长，实际结果越可能因迁移、转职变化和其他岗位需求而偏离。农民是潜在转职来源，不直接算作现有劳工。

本国同市场同商品的已安排产能越接近「供需缺口加需求的 10%」，越少追加建设；达到额度后暂停。最后一级允许跨过额度，现有工程不会被撤销。竣工后仍未充分就业的新增产能会继续影响判断。混合手动工程导致归属不清时，普通原产扩建会保守等待。

粮食紧急保障开启且触发时，产粮原产优先处理，并豁免最低价、低价降权及待投产额度；现有岗位满员和其他建造条件仍须满足。

## 手动决议与总督建议

**「重新规划本月全国建造」**可在每月 1～22 日、当月尚未开始安排开工时使用。确认后，重新评估全国已应用且已启用模板的地点，替换本月未执行的计划。它取消通常的扫描数量和候选数量限制，仍遵守建造名额、预算和其他条件。

计算期间保留事件窗口，完成后显示计划工程数与预计支出；0 项也是有效结果。计划采用启动时的设置与模板，之后的修改不影响该计划，23 日起安排开工，次月恢复通常检查。领土较多时可能需要等待。

**「重置自动建造」**保留模板和设置，清除地点分配、报告、冷却、项目追踪及支出记录；换国时可恢复该玩家此前保存的配置。重置后需要重新应用模板，已开工工程继续施工，已花金币不会退还。

总督面板只提供选址和迁移建议，不自动建造、拆除或搬迁。地方与海军建议分别计算，可在面板手动刷新。

当前游戏内验证范围见[游戏内验证指南](runtime_validation.md)，技术入口见[开发与校验](development.md)。
