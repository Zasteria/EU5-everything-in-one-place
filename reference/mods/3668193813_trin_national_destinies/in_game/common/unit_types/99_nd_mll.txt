# ============================================================================
# Mallorca (MLL): custom unit types
# National Destinies mod
# ============================================================================
#
# Vanilla already arms the Catalan-speaking peasant of ages 1 and 2 with the
# almogavar levies, and gives the Catalan crossbowmen, the Catalan galley,
# the caravels, the galleons and the tercio (advances/region_iberia.txt).
# Nothing here repeats those. This file holds what was the islands' own: the
# armed horses of the Repartiment, the villagers of 1450, the guildsmen of
# 1521, the parish militia of the coast, and three ships.
#
# Every stat under copy_from is a DELTA added to the template and then to the
# unit category's own value (common/levies/readme.txt: "EVERY STAT LINE IS
# ADDITIVE, NEVER AN ASSIGNMENT"). Template totals are quoted for the reader
# only; none of them is written in a block.
#
# Levy lines, each ending where history ended it:
#   nobles: the cavalls armats (age 1). No later twin: the duty was paid off
#     in coin more and more, and from age 2 the nobles raise vanilla's
#     plated knights.
#   peasants: the forans (age 3), then with the laborers the parish militia
#     (age 4). The Nova Planta of 1715 disarmed the island, so from age 5
#     they raise vanilla's levy.
#   burghers and laborers: the agermanats (age 3). The Germania was drowned
#     in 1523 and the guilds never armed again.
# Each levy stands about 1.2 times the vanilla levy its pops raise in its
# age (eu5-validate --checks levies), set by hand.

# ----------------------------------------------------------------------------
# Age 1: Cavalls Armats (levy heavy cavalry)
# ----------------------------------------------------------------------------
# The riders owed by the holders of the great shares of 1230: a horse worth
# its price, a hauberk, shield and lance, inspected at muster. Armoured as
# vanilla's mailed knights are (the two damage-taken lines are theirs) and
# drilled to charge as one troop (morale_damage_done), since on an island
# the same hundred men ride together every year. They are the island's
# guard and slow to move off it (movement_speed).
# Template a_age_1_traditions_heavy_cavalry: max_strength 0.2, combat_power 2.6.
# Power 1.208 against the mailed knights' 1.007: 1.20 times.
a_nd_mll_cavalls_armats = {
	is_special = yes
	category = army_heavy_cavalry
	copy_from = a_age_1_traditions_heavy_cavalry
	buildable = no
	levy = yes

	strength_damage_taken = -0.25
	morale_damage_taken = -0.25
	morale_damage_done = 0.2
	movement_speed = -0.25

	country_potential = {
		has_or_had_tag = MLL
	}

	gfx_tags = { heavy_tag }
}

# ----------------------------------------------------------------------------
# Age 2: Uixer (buildable transport)
# ----------------------------------------------------------------------------
# A broad galley with a single mast, a square sail and a door in the stern
# through which horses are led aboard. Jaume Ferrer took one down the coast
# of Africa in 1346. It carries more than a round ship of its day and has a
# deeper hull; under oars and one sail it is slow.
# Template n_age_2_renaissance_transport: speed 6, hull 12, cannons 4,
# transport 0.5, crew 0.05.
n_nd_mll_uixer = {
	is_special = yes
	category = navy_transport
	copy_from = n_age_2_renaissance_transport
	upgrades_to = n_flute
	buildable = yes

	hull_size = 2
	transport_capacity = 0.05
	movement_speed = -0.5

	country_potential = {
		has_or_had_tag = MLL
	}
}
