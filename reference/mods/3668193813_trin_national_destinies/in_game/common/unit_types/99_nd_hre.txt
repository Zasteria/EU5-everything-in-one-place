### Age 5: Kreistruppen (levy infantry) ###
# The Reichsarmee of the 1681 defence ordinance: every Imperial Circle
# owed a fixed quota, and the Diet could call it double or triple (the
# Duplum and Triplum). Numbers are its strength. Its weakness is what it
# was made of: contingents of dozens of estates with their own drill and
# officers, which broke and ran at Rossbach in 1757.
# Successor of the age 4 Reichsheer levy, which the vanilla levy ladder
# passes in this age.
# Base age 5 infantry: max_strength=2.5, combat_power=2.25
a_nd_hre_kreistruppen = {
	is_special = yes
	category = army_heavy_infantry
	copy_from = a_age_5_absolutism_heavy_infantry
	buildable = no
	levy = yes

	max_strength = 0.25
	strength_damage_taken = -0.05
	morale_damage_taken = 0.1

	country_potential = {
		has_or_had_tag = HRE
	}

	gfx_tags = { medium_tag }
}
