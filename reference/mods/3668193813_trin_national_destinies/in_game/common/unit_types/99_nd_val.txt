# ============================================================================
# Valencia (VAL): custom unit types
# National Destinies mod
# ============================================================================
#
# Vanilla already arms the Catalan-speaking peasant of ages 1 and 2 with the
# almogavar levies, and gives the Catalan crossbowmen, the Catalan galley and
# the tercio (advances/region_iberia.txt). Nothing here repeats those. This
# file holds what was the kingdom's own: the brethren of Montesa, the city's
# company of the banner, the riders of the coast guard, and the peasants who
# rose in 1705 and 1808.
#
# Every stat under copy_from is a DELTA added to the template and then to the
# unit category's own value (common/levies/readme.txt: "EVERY STAT LINE IS
# ADDITIVE, NEVER AN ASSIGNMENT"). Template totals are quoted for the reader
# only; none of them is written in a block.
#
# Three levy lines, each ending where history ended it:
#   clergy: the brethren of Montesa (age 1). No later twin: the order's
#     mastership went to the Crown in 1587 and no vanilla levy competes for
#     clergy, so the same knights are raised, ever more out of date.
#   burghers: the Centenar (age 2) and its arquebusiers (age 3). The company
#     was dissolved in 1707, so from age 4 the burghers raise vanilla's levy.
#   peasants and laborers: the maulets (age 5) and the partides (age 6).

# ----------------------------------------------------------------------------
# Age 1: Frares de Montesa (levy heavy cavalry)
# ----------------------------------------------------------------------------
# Knight brethren of the Order of Montesa, under the rule of Calatrava: mail,
# lance and a white mantle. Few, well armoured and sworn not to leave the
# field without their master's leave (the morale line). They ride out of
# their own commanderies and are slow to gather beyond them (movement_speed).
# Template a_age_1_traditions_heavy_cavalry: max_strength 0.2, combat_power 2.6.
a_nd_val_frares_de_montesa = {
	is_special = yes
	category = army_heavy_cavalry
	copy_from = a_age_1_traditions_heavy_cavalry
	buildable = no
	levy = yes

	morale_damage_taken = -0.05
	movement_speed = -0.25

	country_potential = {
		has_or_had_tag = VAL
	}

	gfx_tags = { crusader_tag heavy_tag }
}
