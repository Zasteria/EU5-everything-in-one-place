# === Iraq Heritage Advances ===
#
# The spine of this tree is water. Mesopotamia was the richest tax province in
# the Islamic world because the Sawad was irrigated, and it stopped being that
# when the Nahrawan canal was breached during the fighting between Ibn Ra'iq
# and Bajkam in 937 and never properly repaired. Sawad tax receipts fell 48%
# between 846 and 918 and kept falling. The sack of 1258 finished a patient
# already dying. Every age of this tree returns to the same question: who digs
# the canals, who pays for them, and who gets the water.
#
# The second thread is that Mesopotamia is plural and stayed plural. Baghdad
# Sunni and caliphal, Kufa and Karbala Shia and shrine-bound, the Jazira
# Syriac, the marshes Mandean and Madan, the north Kurdish and Turkoman. The
# formable admits Sunni and Shia formers alike, so nothing here presumes which.
#
# Differentiation, checked against the neighbours in this space:
#   BNH / NIN own the Syriac Christian upper Jazira, the Patriarchate, the
#     Assyrian imperial revival, and riverine fleets. Nothing here repeats them.
#   KHL owns the universal caliphate, the Bayt al-Hikma and the Hajj. IRQ is the
#     regional tier below it and reaches for the Mustansiriya and the stationers'
#     market instead, which are Baghdad's own institutions rather than Islam's.
# Vanilla coverage for this tag is the Muslim religion tree plus one Crescent
# ship unlock. Keys already granted there (tolerance_own, monthly_devotion 0.1,
# tolerance_heathen at age 3, global_clergy_max_literacy) are avoided.

# ===== DESTINY TREE =====
# Root + 2 paths x 3 stages = 7 advances.
#
# The formation event asked which Baghdad this state is rebuilding, and the
# destiny tree is the answer carried out. Path A (Dar al-Khilafa) is the
# political capital: the Zagros passes the plain cannot live without, the
# western wing in Syria, and finally the shadow caliph in Cairo brought home.
# Path B (Madinat al-Salam) is the civilizational capital: the instruments of
# Maragha, the water machines of the Banu Musa and al-Jazari, and a star
# catalogue recomputed for Baghdad's own meridian.
#
# The root belongs to both, because whichever Baghdad gets built it still eats
# off the Sawad. The heritage tree digs on emergency three times over (the
# Nahrawan breach, the muqasama assessment that makes the treasury care, the
# Hindiyya channel and its quarrel). None of them leaves behind an office. The
# root does: a standing register of the water, which is the thing neither the
# caliphs nor the pashas ever kept.

nd_irq_destiny = {
	age = age_1_traditions
	depth = 0
	potential = { has_or_had_tag = IRQ has_variable = nd_irq_formed has_game_rule = nd_destinies_enabled }
	allow = { stability >= 75 }
	icon = valley_irrigation
	global_monthly_food_modifier = 0.05
}
