# ===== Outremer (OUT): National Destinies =====
# Zero tag advances in vanilla. The Catholic religion tree already covers
# devotion, inquisition, missions and conversion, and Outremer is the one
# Catholic country in the game that cannot use any of it: its own formation
# clause caps Catholics at half the population. So this tree is about the
# other job, the one the Franks actually did for two centuries. Governing
# through the ra'is and the dragoman, guaranteeing courts the crown does not
# own, guarding sanctuaries of faiths the crown does not profess, paying for
# a pilgrimage the crown does not make, and living with military orders and
# Italian communes that hold real jurisdiction inside the realm.
#
# Tolerance is not flavour here. Estate religion (game concept) sets each
# estate's satisfaction and power from the crown's tolerance of THAT
# estate's faith, and in Outremer most estates are heathen or heretic by
# definition. Heathen and heretic tolerance is this country's stability.
#
# Design note for future agents: the dhimmi estate and its full modifier
# suite (dhimmi_estate_levy_size, dhimmi_estate_allowed_in_cabinet and the
# rest) would be a perfect fit and is deliberately NOT used. The scripted
# trigger is_dhimmi requires owner.religion.group = muslim, so a Catholic
# Outremer has no dhimmi estate and every one of those keys is inert.
# Changing that means overriding a shared vanilla scripted trigger that
# every Muslim country in the game depends on, which is not a per-country
# decision.

# ===== DESTINY TREE =====
# The formation event asked one question, and it is the country's own
# formation clause: on what basis does a Latin crown govern subjects it is
# forbidden to convert. These two branches are that question followed to its
# ends. The third founding settlement, the New Towns, has no branch here.
#
# Path A, the Compact of the Courts, is the constitutional answer. The crown
# guarantees other people's law, extends the guarantee to a kingdom and a
# church outside the realm, prints in every script the guarantee is written
# in, and pays for all of it twice over: in service it will never be owed, and
# in standing it will never have in Christendom. Its objectives are
# learning, two built up cities and two jurisdictional seats, not a war map.
#
# Path B, Custodian of the Sanctuaries, is the fiscal answer. The crown owns
# the sea that the pilgrimage and the pepper both cross, from the African
# crossing at Aydhab to the Gulf mouth at Hormuz to the pepper coast itself,
# and pays for it in a field army nobody funds.
#
# No tolerance modifier, no conversion speed and no holy war score appears in
# either branch, exactly as in the heritage tree above. Those three things are
# what this country is defined by not having. The dhimmi estate keys are
# likewise absent and deliberately so: is_dhimmi requires a Muslim owner, so
# every key in that family is inert under a Catholic crown.

nd_out_destiny = {
	age = age_1_traditions
	depth = 0
	potential = { has_or_had_tag = OUT has_variable = nd_out_formed has_game_rule = nd_destinies_enabled }
	allow = { stability >= 75 }
	icon = frankokratia_frankokratia_advance

	stability_cost_efficiency = 0.15
}

# --- PATH A: THE COMPACT OF THE COURTS ---

# Cilician Armenia: a Christian kingdom outside the realm with its own church,
# its own catholicos at Sis and its own written law. In 1265 Smbat Sparapet,
# constable of that kingdom, translated the Assises of Antioch into Armenian.
# The French original is lost. The law of Frankish Antioch survives today only
# in the Armenian that a foreign constable put it into, which is the compact's
# whole argument in a single manuscript.
nd_out_dest_assises_in_armenian = {
	age = age_1_traditions
	requires = nd_out_destiny
	potential = { has_or_had_tag = OUT has_variable = nd_out_formed has_game_rule = nd_destinies_enabled }
	allow = {
		custom_tooltip = {
			text = nd_out_path_a_tt
			has_variable = nd_out_path_a
		}
		owns_or_non_sovereign_subject_owns = location:sis
		owns_or_non_sovereign_subject_owns = location:tarsus
		# Sis, seat of the catholicos and of the Armenian court: 20 in 1337,
		# asked to grow by a quarter (scripts/development_estimate.py).
		custom_tooltip = {
			text = nd_out_dest_sis_developed_tt
			location:sis = {
				owner ?= root
				development >= 25
			}
		}
	}
	icon = laws

	global_integration_speed_modifier = 0.1
	clergy_estate_target_satisfaction = 0.05
	global_manpower_modifier = -0.05
}

# A realm whose statutes are valid in six jurisdictions must promulgate them in
# six scripts. The presses follow the courts: Hebrew type at Acre, Armenian at
# Sis, Syriac for the Eastern bishops, Greek, Arabic and the chancery's own
# Latin. The permanent cost is Christendom's opinion of a Catholic emperor who
# licenses the printing of other people's scripture.
nd_out_dest_six_scripts = {
	age = age_1_traditions

			text = nd_out_dest_acre_developed_tt

				development >= 43
			}
		}
		gold >= 2000
	}
	icon = ven_printing_industry

	research_speed_modifier = 0.05
	global_max_literacy = 5
	monthly_prestige = -0.05
}
