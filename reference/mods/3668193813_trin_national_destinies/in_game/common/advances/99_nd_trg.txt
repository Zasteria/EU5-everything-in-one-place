##############################
# Tuareg (TRG): National Destinies Advances
#
# The confederation of the drum groups as a whole: the Kel Ahaggar, Kel
# Ajjer, Kel Adagh and Iwellemmedan. The Sultanate of Agadez and the Kel Ayr
# are Air's tree (99_nd_air.txt) and a country can hold both, so nothing
# here repeats Agadez, Bilma, the takouba, the inadan or the mehari.
#
# Vanilla gives the tag six advances of its own (advances/country_tle.txt:
# Tin Hinan, protection tariffs, the warrior caste, the silversmiths, the
# mehari corps, the blue robes). Their modifier keys are not granted here in
# the same age.
#
# Attachment points: wherever an unlock matters to play, the parent is an
# advance with no institution gate on its chain (or, in age 1, feudalism,
# which Tadmekka holds in 1337). A desert tribe embraces banking, printing
# or pike and shot late, and an unlock hung under one of those would sit
# out of reach for a century.
##############################

# ===== DESTINY TREE =====
#
# Two roads out of the formation choice (nd_trg.1). Both rest on what the
# confederation's land is in the installed game: eleven desert locations of
# tribesmen, no town among them, no camels in their markets.
#
# Path A keeps the tents free. Its measure is tribesmen, counted: the three
# stages ask for 120, 170 and 250 thousand of the 376 thousand Tuareg
# tribesmen the 1337 setup holds (06_pops.txt). The numbers stay and the
# lands of the two confederations outside the formable are named, so the
# task reads as uniting the drum groups (owner's rulings 2026-10-02). The
# first two stages name land that holds their number. The last one does
# not, on purpose: it names the three chief camps of the Iwellemmedan and
# its texts say the rest of that confederation is meant, so the count is
# read as "bring in the others". Tribesmen in the 1337 setup, in thousands,
# for a country that owns the land itself:
#   the eleven locations of the formable                         101.06
#   stage 1  Tahoua 10.51, Abalak 15.46 (Iwellemmedan)           127.03
#   stage 2  Gao 10.67, Bamba 1.88, and the Kel Gress (KGS) at
#            Ollelewa 14.86, Guidimouni 13.68, Aderbissinat 10.28 178.40
#   stage 3  Kabara 1.09 (Taoudenni and Araouane hold none), and
#            the Iwellemmedan (IWL) at Birni Ader 10.51, Kalfou
#            11.88, Tondikandia 15.83                             217.71
# Stage 3 is 32.29 short of its 250. The ten other Iwellemmedan locations
# hold 77.29 (Kaouara 13.73, Loga 13.24, Dongondoutchi 10.83, Gotheye 8.42,
# Ouallam 6.14, Walata 5.67, Hamdallaye 5.09, Koure 4.92, Boubon 4.90,
# Goudel 4.36) and the Kel Gress's Zinder and Kelle 16.58. Naming enough
# land to reach 250 took nine locations beyond stage 1, six of them in
# stage 3 (the Kel Gress hold 55.40 in five locations and the Iwellemmedan
# 141.47 in fifteen, none above 15.83); the owner ruled for fewer.
# Why these three: the confederation's eastern branch was centred in the
# Azawagh near Tahoua (en.wikipedia.org/wiki/Iwellemmedan_people), which
# on this map is the Ader province, and Birni Ader and Kalfou are the two
# Iwellemmedan locations of it that stage 1 does not name; Tondikandia is
# the largest of all fifteen. The western branch's centre, Menaka, is not
# a location of the game.
# Nobody owns any of the six in 1337. Two things the files do not settle
# and only the running game can: whether the people of a landless society
# count for the country that comes to own the land they live on (the sums
# above assume they do), and whether land held through a subject, which
# meets the ownership line, adds to a count the engine describes as "in
# the current country" (assumed not). The path's map is the one the drum
# groups rode in history: the Azawagh, the river bend, the salt road down
# to Kabara. Timbuktu itself is never asked for, because the Tuareg ruled
# it from outside its walls.
#
# Path B gives the amenokal a seat. Its measure is towns: Tadmekka and
# Takedda raised from camps (8 and 13.8 thousand people in 1337, and a town
# needs 5, location_ranks/00_default.txt), Ghat grown to twice its 1337
# development (5, scripts/development_estimate.py --explain ghat), and the
# northern oasis markets its caravans depended on.
#
# No goal of Air (Katsina, Alkalawa, Kano, Ngazargamu, Sokoto, Bilma,
# Timbuktu, owning Ghat), of the Almohads (Wadan, Walata, Timbuktu, Djenne,
# Niani, banking, gold in the capital market) or of Carthage is repeated: a
# Tuareg country can hold all four trees.

nd_trg_destiny = {
	age = age_1_traditions
	depth = 0
	potential = { has_or_had_tag = TRG has_variable = nd_trg_formed has_game_rule = nd_destinies_enabled }
	allow = { stability >= 75 }
	icon = ahg_amenokal_paramount
	stability_decay = -0.00025
}

# --- Path A: The Free Tents ---

# Stage 1: the Iwellemmedan leave the Adagh for the Azawagh (under
# Karidenna, late 1600s). Tahoua and Abalak are Tuareg pasture nobody owns
# in 1337: Iwellemmedan pops live there as a society without land.
# Camels: no market of the Sahel produces them, so this asks for the Salt
# Cure Grounds (nd_trg_cure_of_the_salt_pastures) or a trade that brings
# them. Not counted by validate_destiny.py, which sees the other three.
nd_trg_dest_azawagh = {
	age = age_1_traditions
	requires = nd_trg_destiny
	potential = { has_or_had_tag = TRG has_variable = nd_trg_formed has_game_rule = nd_destinies_enabled }
	allow = {
		custom_tooltip = {
			text = nd_trg_path_a_tt
			has_variable = nd_trg_path_a
		}
		owns_or_non_sovereign_subject_owns = location:tahoua
		owns_or_non_sovereign_subject_owns = location:abalak
		custom_tooltip = {
			text = nd_trg_dest_tribesmen_120_tt
			pop_type_population_in_country = {
				pop_type = pop_type:tribesmen
				value >= 120
			}
		}
		capital ?= {
			market ?= {
				OR = {
					is_produced_in_market = goods:camels
					is_traded_in_market = goods:camels
				}
			}
		}
	}
	icon = skilled_cavalry_raids
	land_unit_attrition = -0.1
	levy_recovery_modifier = 0.1
}
