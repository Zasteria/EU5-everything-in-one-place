##############################
# Dalmatia (DAL): National Destinies Advances
##############################
#
# Vanilla 1.4 gives a Dalmatian country eighteen advances of its own (six by
# the tag DAL, six by Dalmatian culture, six by the tag RAG on the main road).
# On 2026-10-02 the advances of this tree that told the same institution as
# one of those were given another: the statute of 1272, the commune, the
# quarantine, the argosy yards, the Morlach levy, the literary academy, the
# maritime insurance and the Illyrian movement. Each KEY keeps its first name
# (events, saves and translations hang on it); the comment above the advance
# says what it tells now.

### Age 1: Traditions ###

# Unlock: Fondaco building: Dalmatian trade warehouse
nd_dal_fondaco_tradition = {
	age = age_1_traditions
	potential = { has_or_had_tag = DAL }
	# Not trade_caravans: that advance is potential-gated to Central Asian
	# capitals, so it never appears for Dalmatia and this advance was
	# unresearchable (Workshop report, 2026-08-04).
	requires = trade_advance_age_of_trad
	icon = merchant_power_from_maritime_reformation_advance
	unlock_building = nd_dal_fondaco

	trade_sea_efficiency = 0.1

}
