# ===== Francia (FRK) Heritage Advances =====
# Francia can only be proclaimed after the Holy Roman Empire has ended, so
# in most campaigns it forms in the ages of Reformation to Revolutions and
# researches its earlier advances afterwards. Buildings sit early because a
# building stays useful whenever it is researched; units sit in ages 4 to 6
# where the realm actually exists to field them.
#
# Kept clear of the feeders: vanilla France (country_FRA.txt), Lotharingia
# (scara cavalry, palatine chapel, prince-bishops, Rhine tolls) and Greater
# Burgundy (ordonnance and gendarmes, Carolingian palatium). France's destiny
# owns expansion to the Rhine and the Channel; nothing here is about either.

# ==========================================
# Age 1: Traditions. The Carolingian foundations
# ==========================================

# ===== DESTINY TREE =====
# Francia's second act. nd_frk.1 chose the founding principle and set
# nd_frk_path_a or nd_frk_path_b; each path carries it past the formation
# territory into the lands Charlemagne's realm held beyond it.
# Path A, one law over all: the old duchies east of the Rhine brought under
# the realm's own counts. Its objectives use plain owns, not
# owns_or_non_sovereign_subject_owns, because direct rule IS the path: a march
# holding Paderborn is the other path's answer.
# Path B, the law of the peoples: a ring of marches and subject princes from
# the Pyrenees to the Eider and down Italy to Benevento, judged on subject
# structure, treasury and standing as much as on land.
# Path A measures each stage by a share of its own target areas, not by
# total_development: a Francia contains France, which alone starts near
# 3,440 development, so realm-wide clauses were met on formation.
# Keys are clear of the heritage tree, nd_frk.1, and the destiny trees of
# France, Greater Burgundy and Lotharingia, which a Francia can inherit.

nd_frk_destiny = {
	age = age_1_traditions
	depth = 0
	potential = { has_or_had_tag = FRK has_variable = nd_frk_formed has_game_rule = nd_destinies_enabled }
	allow = { stability >= 75 }
	icon = crown_power_advance_renaissance
	antagonism_received_modifier = -0.1
}
