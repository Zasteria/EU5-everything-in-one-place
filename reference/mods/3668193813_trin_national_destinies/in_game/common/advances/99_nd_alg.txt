# National Destinies: Algiers (ALG) heritage advances.
#
# Vanilla already tells the kasbah, the Thaalibi emirs, the Algiers emporium,
# the corsair state, the Janissary ojaq, the deylik and the consuls
# (advances/country_alg.txt, region_maghreb.txt), and a country that formed
# Algiers from Tlemcen keeps Tlemcen's seven advances beside them
# (country_tle.txt). This tree tells the rest: the Zayyanid inheritance, the
# Andalusi refugees, the city's works and guns, the three beyliks, the
# captive economy, the Kabyle companies, the grain trade and the Emir's state.
# No key of a vanilla identity advance is granted in the same age.

# ===== DESTINY TREE =====
# A root and two paths of three stages. The formation event (nd_alg.1) sets
# nd_alg_path_a or nd_alg_path_b, and stage 1 of each path reads it.
#
# Path A, the Well-Guarded City, is earned by wealth, a fleet and the growth
# of Algiers, with one harbour to take per stage. Path B, the Emir of the
# Tell, is earned by conquest of the interior and a standing army. No location
# is asked for by both paths, and none of them is a goal of the Almohad or
# Carthage trees (99_nd_alm.txt, 99_nd_cth.txt).
#
# Every location named below belongs to another country on 1337.1.1
# (main_menu/setup/1337/10_countries.txt) except Algiers and Tahert, which
# Tlemcen holds and which are asked to GROW, not to be taken:
#   Jijel, Bejaia, Setif, Kalaa of Ait Abbas, Constantine: Bejaia (BIJ)
#   Tunis: the Hafsids (TUN)      Biskra, Msila: the Zab (ZAB)
#   Touggourt: TGT                Ouargla: OGL
#
# Development is asked only of a named place this country's history built up,
# measured from its own 1337 value (scripts/development_estimate.py --explain):
#   Algiers 26.8: a small harbour town in 1337, some hundred thousand people
#     by the 1630s. Stage 1 asks a quarter more (34), stage 3 double (54).
#   Tahert 15: the ruined Rustamid capital the Emir rebuilt as Tagdempt in
#     1836. Stage 2 asks half as much again (23).
# The clause is vanilla's own idiom for an advance that reads one location
# (advances/country_yem.txt:77, port_of_aden).

nd_alg_destiny = {
	age = age_1_traditions
	depth = 0
	potential = { has_or_had_tag = ALG has_variable = nd_alg_formed has_game_rule = nd_destinies_enabled }
	allow = { stability >= 75 }
	icon = maghrebi_administration
	# The middle land of the Maghreb, which no one held for long. Prestige
	# stands in the formation modifiers already, so the root steadies the
	# provinces.
	global_separatism = -0.05
}
