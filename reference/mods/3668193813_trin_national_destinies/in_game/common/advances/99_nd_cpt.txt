# Coptic Egypt: heritage advances.
#
# The thesis, and the test every line here has to pass: this is a MINORITY
# regime. Its power is the ledger, its refuge is the desert and the marsh, its
# ally is upriver, and its enemy is time. Copts were roughly a fifth of Egypt
# in 1337 and falling fast (the riots of 1301 and the sixty churches pulled
# down in 1321 were recent memory, and conversion accelerated after both). So
# nothing in this tree reads as a normal Christian kingdom: there is no
# crusading arm, no naval empire, no imperial claim. AEG owns the imperial
# restoration of Egypt and EGY owns the Mamluk sultanate; CPT owns the far
# stranger thing, a state run by the people who keep its accounts.
#
# Deliberately NOT here: a fleet. Egyptian naval identity is EGY's felucca and
# Nile galley and AEG's Bahriyya; a riverine minority regime that has to buy
# its cavalry has no business also owning the sea.
#
# Vanilla already gives every Miaphysite country 31 advances (Alexandrian
# primacy, the School of Alexandria, monastic architecture, conversion speed,
# tolerance). Those themes are absent below on purpose.

# ===== DESTINY TREE =====
#
# The country's clock is demographic and the engine runs it. `is_dhimmi`
# requires the owner's religion group to be Muslim, so a Miaphysite Egypt has
# no dhimmi estate at all: forming CPT dissolves the legal category of Copt
# and folds the Sunni majority into the ordinary peasant and burgher estates.
# The parliamentary procedure that made this state runs backwards through
# those estates, and it gets easier every decade.
#
# The two destinies are the two honest answers to that.
#
# Path A concedes the arithmetic and makes it irrelevant: keep every court,
# every endowment and every mosque exactly where it is, and be so completely
# indispensable that no chamber ever wants the clerks gone. It is fought with
# institutions, markets and money, not armies.
#
# Path B attacks the arithmetic: the church becomes territorial, the sees of
# Saint Mark are held as ground rather than consecrated in absentia, and the
# realm's Christian share rises by conquest of Christian and formerly
# Christian country upriver as much as by preaching at home.
#
# Neither path touches AEG's Pharaonic and Mamluk restoration: no Levant, no
# Hedjaz, no Suez, no imperial claim. CPT stays the narrower thing and leaves
# Aegyptus its material.

nd_cpt_destiny_root = {
	age = age_1_traditions
	depth = 0
	potential = { has_or_had_tag = CPT has_variable = nd_cpt_formed has_game_rule = nd_destinies_enabled }
	allow = { stability >= 75 }
	icon = crown_power_advance_renaissance
	country_cabinet_efficiency = 0.05
}

# ===== PATH A: THE LEDGER KEEPS THE STATE =====

# The four chief judges of Cairo, one to each school of law, keep their bench
# under a Christian crown. Marriage, inheritance and endowment stay where they
# were. The khutba cannot name this sovereign, so it names the Abbasid caliph
# who has lived in Cairo since 1261, and nobody is asked to pretend otherwise.
nd_cpt_dest_qadis_kept = {
	age = age_1_traditions
	requires = nd_cpt_destiny_root
	potential = { has_or_had_tag = CPT has_variable = nd_cpt_formed has_game_rule = nd_destinies_enabled }
	allow = {
		custom_tooltip = {
			text = nd_cpt_path_a_tt
			has_variable = nd_cpt_path_a
		}
		stability >= 75
		gold >= 1000
		has_embraced_institution = institution:banking
		any_market_present_in_country = {
			OR = {
				is_produced_in_market = goods:pepper
				is_traded_in_market = goods:pepper
			}
		}
	}
	icon = a_tolerant_society
	tolerance_heathen = 1
	tax_income_efficiency = 0.05
}
