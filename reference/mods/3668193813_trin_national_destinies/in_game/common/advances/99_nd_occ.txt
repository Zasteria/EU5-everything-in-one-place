# ============================================================================
# Occitania (OCC): heritage advance tree
# National Destinies mod
# ============================================================================
#
# Vanilla coverage for this tag is one region advance (unlock_galiot, age 4,
# any French/Iberian/Italian capital). There is no Occitan, Languedocien or
# Gascon culture advance set at all, so this tree is the player's entire
# advance experience for the Midi and is built at destination density.
#
# The thesis: Occitania is a country of written instruments. Charters, fors,
# costumas, notarial acts, poetic laws, consular oaths and provincial estates
# are how it governs, and it deliberately standardised its own vernacular as
# a literary and legal language while the north was still writing custom down
# from memory. Its wealth is one dyestuff. Its politics is a permanent
# negotiation between two crowns. Its religious history is a suppression it
# never forgot, which is exactly why the next dissent found a home here.
#
# On Catharism: the Albigensian Crusade ended in 1229, Montsegur fell in 1244
# and Guilhem Belibaste, the last known perfectus of the Languedoc, was burned
# at Villerouge-Termenes in 1321, sixteen years before the game starts. There
# is no Cathar church left to restore and this tree does not pretend there is.
# What survives in 1337 is grievance, confiscated land and an inquisitorial
# apparatus, and that is what nd_occ_erenca_catara models.
#
# Deliberate non-overlap: BGP holds the troubadour court and the Avignon
# papacy, CDA holds Catalan maritime law and the Barcelona shipyards, GBU
# holds the Flemish cloth cities, GOT holds Visigothic law and the Narbonne
# staple. Nothing here depends on holding the Narbonne coastal corridor.
#
# 41 advances, 25 with an unlock (61%).

# ============================================================================
# ===== DESTINY TREE =====
# ============================================================================
#
# The formation fork is constitutional, so the destiny tree is too. Both paths
# are the same country pursued to its logical end, and neither is a rerun of
# the heritage tree above: nothing here touches the Consistori, the Leys, the
# capitouls, the pastel, the canal, the Chambre de l'Edit or the Felibrige,
# and nothing here reopens Catharism, which ended at Villerouge-Termenes in
# 1321 and is treated in this mod as archive and land settlement only.
#
# Path A, Lo Pacte Consular: authority rises out of the charters, so the
# country grows by admitting towns to the pact and by credit, franchise and
# market rather than by summons. Its geography is the river valleys of the
# interior: the Quercy, the Garonne down to the ocean, and the Occitan north.
#
# Path B, Tenc de Degun: authority descends from a prince who does homage to
# nobody, which is only true while he holds the doors. Its geography is the
# Pyrenean crest and the far slope: the Basque passes, Navarre by inheritance,
# and finally Aragon, whose king died at Muret in 1213 for the Occitan lords.
#
# No location is used by both paths, and nothing here requires Narbonne, which
# Regnum Gothorum (GOT) contests.

# ----------------------------------------------------------------------------
# Root
# ----------------------------------------------------------------------------
nd_occ_destiny = {
	age = age_1_traditions
	depth = 0
	potential = { has_or_had_tag = OCC has_variable = nd_occ_formed has_game_rule = nd_destinies_enabled }
	allow = { stability >= 75 }
	icon = crown_rights_laws_advance

	global_distance_from_capital_speed_propagation = 0.1
	max_diplomats = 1
}

# circle; the cardinals elected a Cahorsin pope in 1316. The Quercy lies
