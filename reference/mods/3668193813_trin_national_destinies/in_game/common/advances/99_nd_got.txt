# Regnum Gothorum (GOT): Advance tree
# National Destinies mod
#
# WHAT THIS TREE IS ABOUT. Spain (SPA) is the completion of the Reconquista
# and the Atlantic empire that followed it. Al-Andalus (ADU) is the Islamic
# peninsula. The Aragonese Empire (CDA) is a Mediterranean thalassocracy of
# consulates and galleys. This tree is none of those. It is the survival of a
# late-antique state: one territorial law binding Goth and Roman alike, a
# joint council of crown and church that legislates for the whole kingdom, a
# single primatial see over all Iberia, and a realm whose spine runs overland
# from Toledo across the Pyrenees to Narbonne. There are deliberately NO
# warships in this tree. A kingdom that had to fight for Septimania to exist
# is a land-corridor power, and saying so is the point.
#
# ELECTIVE KINGSHIP IS NOT SPENT HERE. Canon 75 of the Fourth Council of
# Toledo (633) made the kingship formally elective and anathematised
# regicide, which Frankish writers still called the morbus Gothorum. That
# tension against hereditary Castilian practice is the natural axis for the
# destiny tree, so this tree only gestures at it (the unction of Wamba) and
# leaves the question open.
#
# VANILLA COVERAGE, NOT DUPLICATED. Castilian-cultured countries already get
# cas_lanzas_de_castilla (age 3 unit unlock); Iberian Catholics get
# conquistador_advance (age 3); the Iberian region gets saquiyah (age 1
# irrigation) and unlock_galiot (age 4 ship). None of those themes recur
# below.
#
# Stepping-stone density (4-6 per age): ROM at L5 is reachable from here.
# Total: 29 advances, 18 unlocks (62%).

# Liber Iudiciorum: begun by Chindasuinth (642), promulgated by Recceswinth
# after revision at the Eighth Council of Toledo (654). Twelve books, 526
# laws, in Latin. Its innovation was not its content but its reach: it was
# TERRITORIAL, replacing the older system in which Goths were judged by
# Gothic law and Romans by the Breviary of Alaric. One code, one jurisdiction,
# every subject. It survived the kingdom, translated as the Fuero Juzgo, and
# was still being granted as municipal law in the thirteenth century.
nd_got_liber_iudiciorum = {
	age = age_1_traditions
	potential = { has_or_had_tag = GOT }
	requires = codified_laws
	icon = lawcode_of_suleiman

	unlock_building = nd_got_liber_court

	# One law over many peoples is exactly what cultures_capacity models.
	cultures_capacity = 1
	legislative_efficiency = 0.05
	global_separatism = -0.03
}

# Councils of Toledo: eighteen synods between 400 and 702, convoked by the

# ===== DESTINY TREE =====
# Post-formation mission objectives.
#
# THE SPINE IS THE SUCCESSION. Canon 75 of the Fourth Council of Toledo (633)
# made the kingship formally elective and anathematised anyone who took it by
# violence; the practice was seven depositions in seventy years and a Frankish
# nickname, the morbus Gothorum. The heritage tree poses that question at the
# unction of Wamba and refuses to answer it. These two paths answer it, in
# opposite directions, and the answer determines everything else.
#
# Path A (nd_got_path_a, Regnum Gothorum) takes Canon 75 literally: the crown
# is an OFFICE conferred by the assembly of magnates and bishops, held out of a
# written code, and separable from the man who wears it. Its objectives are the
# Septimanian sees (the canon says the bishops of the WHOLE people, so the
# Gothic episcopate must be whole), then institutions, treasury and development.
# It is the non-conquest path: its capstone is bought with money, law and
# growth, not with an army.
#
# Path B (nd_got_path_b, Reiki Gutane) answers the other way: the crown belongs
# to the BLOOD, secured the only way a Gothic king ever beat an election, by
# having the heir crowned in the father's lifetime while the sworn men are still
# there to swear. Its objectives follow the gens rather than the office: the
# strait lost in 711, Theodoric's Italy, and finally the Crimean Goths at
# Theodoro, whom the game itself gives gothic_culture and whom Busbecq found
# still speaking the language in 1562.
#
# No location appears on both paths. The heritage tree's four institutional
# hooks (the Liber as Fuero Juzgo, the councils, Toledan primacy, Guarrazar)
# are not touched here.

nd_got_destiny = {
	age = age_1_traditions
	depth = 0
	potential = { has_or_had_tag = GOT has_variable = nd_got_formed has_game_rule = nd_destinies_enabled }
	allow = { stability >= 75 }
	icon = crown_power_advance_renaissance

	# The one part of the constitution the councils left open is the making of
	# a king, so the fundamental law is genuinely up for revision.
	government_reform_slots = 1
	# A crown that is an institution does not fall with the man who wears it.
	stability_decay = -0.0002
}

# seventy-fifth canon set the rule: the king is raised by the common consent of
# the magnates and the bishops of the whole people, and whoever takes the crown

# episcopate sits beyond the Pyrenees under a foreign crown, so the province of

# Stage 3A: rex sub lege. Isidore's line, taken by the lawyers as a rule of
# forfeiture: rex eris si recte facias, si non facias non eris. A crown
# conferred by an assembly out of a written code is held on the code's terms
# and can be lost on them. The capstone of this path is bought with law,
# treasury and growth rather than with an army, which is the whole point of
# choosing it over the Gothic name. The growth is asked of Toledo, the urbs
# regia where the councils sat: 26 in 1337 (scripts/development_estimate.py),
# doubled for stage three. The letters are the printing press (the code set
# in type so every court reads one text), an institution of the third age,
# so this path ends within two ages of the other.
nd_got_dest_rex_sub_lege = {
	age = age_1_traditions
	requires = nd_got_dest_fiscus_publicus
	potential = { has_or_had_tag = GOT has_variable = nd_got_formed has_game_rule = nd_destinies_enabled }
	allow = {
		has_embraced_institution = institution:printing_press
		gold >= 3000
		custom_tooltip = {
			text = nd_got_dest_toledo_developed_tt
			location:toledo = {
				owner ?= root
				development >= 52
			}
		}
		prestige >= 75
		stability >= 75
	}
	icon = pal_a_just_ruler

	# A crown that is a legal person absorbs other crowns as offices, keeps its
	# subjects by law rather than by garrison, is cheaper to keep steady because
	# the realm obeys the office and not the man, and builds its cities because
	# the revenue it spends was never anyone's private purse.
	diplomatic_annexation_efficiency = 0.2
	subject_loyalty = 5
	stability_cost_efficiency = 0.1
	global_urban_build_buildings_efficiency = 0.2
}

# ----------------------------------------------------------------------------
# PATH B: REIKI GUTANE (the crown as blood and oath)
# ----------------------------------------------------------------------------

# Stage 1B: the king crowned in his father's life. Chindasuinth was eighty and
# Braulio of Zaragoza wrote urging it, and on 20 January 649 Recceswinth was
# crowned beside his living father. Leovigild had done the same for Hermenegild
# and Reccared, Egica did it for Wittiza. Association defeats the election by
# timing rather than by argument: the sworn men swear to the son while the
# father breathes. A king made by his own men owes them a war, and the oldest
# debt is the strait, which Julian of Ceuta opened in 711.
nd_got_dest_rex_cum_patre = {
	age = age_1_traditions
	requires = nd_got_destiny
	potential = { has_or_had_tag = GOT has_variable = nd_got_formed has_game_rule = nd_destinies_enabled }
	allow = {
		custom_tooltip = {
			text = nd_got_path_b_tt
			has_variable = nd_got_path_b
		}
		owns_or_non_sovereign_subject_owns = location:ceuta
		owns_or_non_sovereign_subject_owns = location:tangier
		army_size >= 30
	}
	icon = ues_strong_dynastic_ties

	army_light_cavalry_power = 0.15
	land_unit_attrition = -0.1
}

# Stage 2B: one people, two kingdoms. Theodoric the Amal ruled Italy from
# Ravenna, married his daughter to the Visigothic king, and after Vouille (507)
# held both Gothic realms in one hand until 526. A crown that claims a people
# rather than an office claims the whole people, and the other half is buried
# at Ravenna. Verona was Theodoric's own city, remembered in German verse as
# Bern.
nd_got_dest_gens_una = {
	age = age_1_traditions
	requires = nd_got_dest_rex_cum_patre
	potential = { has_or_had_tag = GOT has_variable = nd_got_formed has_game_rule = nd_destinies_enabled }
	allow = {
		owns_or_non_sovereign_subject_owns = location:ravenna
		owns_or_non_sovereign_subject_owns = location:verona
		army_size >= 50
		prestige >= 50
	}
	icon = warriors_unity

	military_tactics = 0.1
	army_maintenance_efficiency = 0.1
	# The claim is that no land the gens holds is foreign ground.
	morale_recovery_in_friendly = 0.05
}

# Stage 3B: the tongue still spoken. In 1562 Busbecq wrote down eighty six
# words from two envoys of the Crimean Goths at Constantinople: broe for bread,
# ada for egg, reghen for rain, handa for hand. Their principality was Theodoro
# at Mangup, in the province the maps still call Gothia, and the game gives
# theodoro gothic_culture to this day. Kaffa is the Genoese port that was the
# gate to it. This is the hardest objective in the tree by a wide margin, which
# is what a capstone founded on a people rather than an office should cost.
nd_got_dest_gutthiuda = {
	age = age_1_traditions
	requires = nd_got_dest_gens_una
	potential = { has_or_had_tag = GOT has_variable = nd_got_formed has_game_rule = nd_destinies_enabled }
	allow = {
		owns_or_non_sovereign_subject_owns = location:theodoro
		owns_or_non_sovereign_subject_owns = location:kaffa
		army_size >= 75
		prestige >= 75
	}
	icon = manchu_script

	unlock_building = nd_got_dest_thiudangardi

	discipline = 0.05
	# Mangup held five months against the Ottomans in 1475. Getting into it is
	# the last act of the path.
	assault_ability = 0.1
	global_war_score_efficiency = 0.1
}
