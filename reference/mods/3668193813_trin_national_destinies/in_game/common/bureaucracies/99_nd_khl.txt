# National Destinies: Khilafah bureaucracies
# Five historically grounded institutions of the universal Sunni caliphate
# restored under one Caliph from al-Andalus to the Indus. The set spans the
# house where anyone may petition the Caliph (Dar al-'Adl), the audit of every
# provincial treasury (Diwan al-Zimam), the unification of the four Sunni
# madhhabs under the Caliph (Pan-Islamic Ulama Council), the yearly covering
# of the Kaaba (Kiswa of the Kaaba), and the trans-imperial revival of Abbasid
# translation-and-sciences scholarship (Bayt al-Hikmah Network). On the day of
# forming the country's own grant gives 2 places and vanilla 1: 3 of 5
# institutions can run.
#
# Vanilla 1.4 ships generic Islamic bureaucracies for every Muslim country
# (bureaucracies/muslim.txt), and the Khilafat is Sunni by its formable's
# own gate, so it holds those as well. Three blocks here carried the same
# office as a vanilla one: the Mazalim court and the Bayt al-Mal under the
# same names, and the pilgrimage caravan, which vanilla calls Diwan
# al-Hajj. Each now carries an institution that only a Caliph has. Their
# KEYS are unchanged, because saves and the impact modifier registry refer
# to them, so khl_bayt_al_mal_bureaucracy is now the audit bureau and
# khl_hajj_caravan_bureaucracy is the covering of the Kaaba.

# 1. Dar al-'Adl (key says diwan_al_mazalim): the House of Justice.
#    Nur al-Din built the first in Damascus around 1163 and sat in it twice
#    a week to hear complaints against his own officers. Baybars moved the
#    hearing of petitions into a new one below the Cairo citadel in the
#    1260s, with the chief judges of the four schools beside him. Vanilla's
#    Mazalim Court is the sovereign's tribunal (legitimacy, a higher
#    ceiling on control, nobles resentful) and this block used to repeat
#    its control key. The House of Justice is the written petition: anyone
#    in any province may complain of any governor and get an answer in the
#    Caliph's name. So the reward is fewer revolts and peasants who recover
#    from a wrong, not a higher ceiling.
khl_diwan_al_mazalim_bureaucracy = {
	implementation_price = price:implement_bureaucracy_price
	maintenance_price = price:maintain_bureaucracy_price
	removal_price = price:remove_bureaucracy_price
	maintenance_price_modifier = {
		value = country_economical_base
		multiply = 0.003
	}

	potential = {
		has_or_had_tag = KHL
		has_game_rule = nd_bureaucracies_enabled
	}

	allow = {
		religion = religion:sunni
	}

	estates_that_like = {
		crown_estate
		peasants_estate
	}
	estates_that_dislike = {
		nobles_estate
	}

	neutral_modifier = {
		num_nd_provincial_estates = 1
	}

	positive_modifier = {
		scale = { value = scope:maintenance }
		# 0.05 a month stood here, ten times vanilla's usual grant (0.001 to
		# 0.005) and a standing balance finding.
		global_monthly_control = 0.003
		monthly_rebel_growth = -0.001
		peasants_estate_satisfaction_recovery = 0.001
	}

	negative_modifier = {
		scale = {
			value = 1
			subtract = scope:maintenance
		}
		global_separatism = 0.10
		global_nobles_estate_power = 0.10
	}
}

# 2. Diwan al-Zimam (key says bayt_al_mal): the bureau of control. The
#    Abbasid caliph al-Mahdi (775-785) set an audit office beside every
#    bureau of state and one above them all, the zimam al-azimma, to check
#    their books. Vanilla's Bayt al-Mal is the treasury that collects and
#    pays out (army upkeep, a higher tax ceiling, estates enriching
#    themselves when it decays), and this block used to share that last
#    key. A realm from al-Andalus to the Indus cannot keep one treasury.
#    It keeps many and audits them: revenue that was assessed arrives,

# 4. Kiswa of the Kaaba (key says hajj_caravan). Not named for the
#    custody of the two sanctuaries, because Aegyptus (Khidmat al-Haramayn)
#    and Arabia (Custodianship of the Two Holy Mosques) already carry that
#    office, and either can go on to form the Khilafat and would then hold
#    two of them. Vanilla's
#    Diwan al-Hajj already organises and provisions the pilgrimage caravan
#    (cheaper pilgrimage actions, conversion), and any Muslim ruler can run
#    one. What only the Caliph does is clothe the Kaaba: a new covering,
#    the kiswa, sent every year since the Abbasid al-Mahdi made the custom
#    annual, paid for under the Mamluks from 1349 out of three Egyptian
#    villages endowed for nothing else, with gifts for the sharifs and the
#    poor of the two cities. Allowed only when the Caliph holds the Holy
#    Cities. No key here is one of vanilla's. The old neglect block took
#    away the same government power the funded block gave (a standing
#    balance finding), and paid out loot, which is ours and not the
#    raiders'. Neglect now costs standing among the courts instead.
khl_hajj_caravan_bureaucracy = {
	implementation_price = price:implement_bureaucracy_price
	maintenance_price = price:maintain_bureaucracy_price

	maintenance_price_modifier = {
		value = country_economical_base
		multiply = 0.005
	}

		has_or_had_tag = KHL
		has_game_rule = nd_bureaucracies_enabled
	}

		owns = location:mecca
		owns = location:medina

		burghers_estate

	neutral_modifier = {
