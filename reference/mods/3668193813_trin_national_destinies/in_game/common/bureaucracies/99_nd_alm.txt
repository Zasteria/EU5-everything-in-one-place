# National Destinies: Almohad bureaucracies
# Four historically-grounded institutions of the Almohad Caliphate (1121-1269)
# and its successor states. The set covers Ibn Tumart's reformer cadre
# (talaba), the inner Berber council (ahl al-jama'a), the Marrakesh chancery
# (the office of the 'alama), and the silver-square mint (sikka almohad) whose
# dinar became the trans-Mediterranean coin standard. On the day of forming
# the country's own grant gives 1 place and vanilla 1: 2 of 4 institutions can
# run.
#
# Vanilla 1.4 ships a generic Diwan al-Insha' for every Muslim country
# (bureaucracies/muslim.txt), and the Almohads are Sunni by their formable's
# own gate, so they hold it as well. Block 3 therefore carries the Almohad
# form of the chancery, not the office itself. Its KEY is unchanged, because
# saves and the impact modifier registry refer to it.

# 1. Talaba: the Almohad cadre of theological-administrative students
#    educated in Ibn Tumart's tawhid doctrine. Drawn first from the Masmuda
#    of the High Atlas, then from the wider empire, the talaba supplied the
#    qadis, provincial governors, and tax assessors of the early Caliphate.
#    They displaced the inherited Maliki ulama as the primary institutional
#    clergy, training a literate class loyal to the Mu'minid dynasty rather
#    than to the long-rooted Andalusi-Maghrebi fuqaha.
alm_talaba_bureaucracy = {
	implementation_price = price:implement_bureaucracy_price
	maintenance_price = price:maintain_bureaucracy_price
	removal_price = price:remove_bureaucracy_price
	maintenance_price_modifier = {
		value = country_economical_base
		multiply = 0.003
	}

	potential = {
		has_or_had_tag = ALM
		has_game_rule = nd_bureaucracies_enabled
	}

	allow = {
		religion = religion:sunni
	}

	estates_that_like = {
		crown_estate
		clergy_estate
	}
	estates_that_dislike = {
		nobles_estate
	}

	neutral_modifier = {
		num_nd_provincial_estates = 1
	}

	positive_modifier = {
		scale = { value = scope:maintenance }
		global_clergy_max_literacy = 10
		global_pop_conversion_speed_modifier = 0.10
		global_estate_target_satisfaction = 0.025
	}

	negative_modifier = {
		scale = {
			value = 1
			subtract = scope:maintenance
		}
		nobles_estate_satisfaction_decay = 0.020
		global_clergy_estate_power = 0.10
	}
}

# 2. Ahl al-Jama'a: the Almohad inner council, descended from Ibn Tumart's
#    original Council of Ten and the broader Council of Fifty, comprising
#    chiefs of the Masmuda confederation (Hintata, Tinmel, Ganfisa, Hargha)
#    alongside the dynastic Mu'minid kin. The jama'a confirmed succession,
#    apportioned campaign commands, and held formal precedence over civil
#    administrators. It made the Almohad state a tribal-aristocratic
#    confederation in caliphal dress, with all the vigor and the brittleness
#    that implied. The same chiefs whose levies broke Castilian armies
#    at Alarcos defected the realm into civil war after Las Navas.

# 3. Office of the 'Alama (key says diwan_al_insha): the Almohad chancery
#    of Marrakesh, named for what set it apart. The 'alama was a short
#    phrase of praise to God in thick letters at the head of every decree,
#    in the ruler's own hand or that of the one secretary trusted with it,
#    and a document without it had no force. About three hundred Almohad
#    chancery letters survive: appointments of governors, news of victories,
#    rulings on doctrine, written in rhymed prose and sent to every province.
#    Vanilla's Diwan al-Insha' is a foreign office (diplomats, relations,
#    annexing subjects). This one faces inward: it is how Marrakesh held the
#    Maghreb and al-Andalus as one administration. Speed of annexation stood
#    here and repeated vanilla's annexation bonus. Integration replaces it.

# 4. Sikka Almohad: the imperial mint of Marrakesh, whose square-flan
#    gold dinar (the dobla almohade) and silver dirham became the most
#    trusted coinage of the western Mediterranean. The Christian crowns
#    of Iberia minted millares in conscious imitation, and Almohad gold
#    circulated as far as the fairs of Champagne. The mint's prestige
#    rested on its purity (98% gold) and the caliph's strict control of
#    the assay; loosen that grip, and the realm's coin debased itself
#    into the inflation of the late Mu'minids.
