###############################################################
# National Destinies: CPT (Coptic Egypt) bureaucracies
#
# Four institutions of a Christian minority state on the Nile.
# This is not an imperial restoration and nothing here reads as
# one: no ceremonial court, no crown-heavy apparatus, no
# conquest office. The country's problem is that it governs a
# population that is four fifths Sunni and getting more so, and
# every institution below is an answer to that problem.
#
#   1. The Altar Lot        : the papal succession at Scetis,
#                             a head of church no crown appoints
#   2. The Kharaji Year     : the Coptic solar tax year and the
#                             flood assessment on Rawda island
#   3. Letters of the Zimam : the accounting hand taught inside
#                             the secretarial families
#   4. Purse of the Arakhina: the lay notable houses that stand
#                             surety for the community
#
# ENGINE FACT, and the reason nothing below touches the dhimmi
# estate: `is_dhimmi` (scripted_triggers/pop_triggers.txt:1)
# requires the owner's religion group to be Muslim. Forming CPT
# dissolves the legal category of Copt entirely and folds the
# Sunni majority into the ordinary peasant and burgher estates,
# so every dhimmi_estate_* key is inert for this country. The
# estates below are the ones the engine actually gives it.
#
# Deliberately NOT here, because CPT already owns them in
# permanent content: the revenue bureau itself (heritage advance
# plus the Diwan office), the flood gauge as a building (the
# miqyas), the archon household as a building, the endowment
# house, the Holy Synod, and destiny's Bureau of Endowments.
# These four are the procedures those buildings run, not the
# buildings again.
#
# On the day of forming the country's own grant gives 2 places: 2 of 4
# institutions can run.
#
# IDs are cpt_-prefixed to avoid collision with EGY, AEG, MAM
# and any future Egyptian formable.
###############################################################


# =====================================================================
# The Altar Lot (al-qur'a al-haykaliyya): the papal succession
#
# The pope of Alexandria is chosen from the monks and never from the
# bishops, since a bishop is espoused to his own see and cannot be
# moved from it. When Michael IV died in 1102 the bishops and priests
# went into the wilderness of Scetis, sat with the elders of the desert
# for days, and came out with Macarius II. Where the assembly could not
# agree, the last names went to the altar and a blindfolded child drew
# one of them. Since 640 the ruler's confirmation of the choice has
# been a formality, which is exactly the point: this is a succession no
# sovereign arranges in advance, and a Coptic crown inherits that
# limitation along with the church.
#
# Working: the see is filled quickly, the community has a head it
# recognises as its own, a village boy who took the habit can end up
# governing the realm's largest institution. Decayed: the see stands
# vacant for years, bishops act on their own authority in their own
# eparchies, and preachers with no chair above them fill the silence.
# =====================================================================
cpt_altar_lot_bureaucracy = {
	implementation_price = price:implement_bureaucracy_price
	maintenance_price = price:maintain_bureaucracy_price
	removal_price = price:remove_bureaucracy_price
	maintenance_price_modifier = {
		value = country_economical_base
		multiply = 0.003
	}

	potential = {
		has_or_had_tag = CPT
		has_game_rule = nd_bureaucracies_enabled
	}

	# The popes are made at Scetis. Lose Wadi el-Natrun and the
	# procedure has nowhere to happen.
	allow = {
		owns = location:wadi_el_natrun
	}

	estates_that_like = {
		clergy_estate
		peasants_estate
	}
	estates_that_dislike = {
		crown_estate
	}

	# The monastic rule means the highest office of the realm is open
	# to men out of villages, which is not true of any bishopric in
	# Christendom that fills its chairs from noble houses.
	neutral_modifier = {
		peasants_estate_allowed_in_cabinet = yes
	}

	# The lot falls, the enthronement happens at Cairo, and the
	# community closes around a head it did not have to be given.
	positive_modifier = {
		scale = { value = scope:maintenance }
		peasants_estate_satisfaction_recovery = 0.001
		monthly_clergy_estate_rebel_growth = -0.005
		stability_investment = small_stability_investment
	}

	# The chair stands empty, nobody consecrates bishops, and every
	# eparchy governs itself while rival preachers work the gap.
	negative_modifier = {
		scale = {
			value = 1
			subtract = scope:maintenance
		}
		global_clergy_estate_power = 0.10
		monthly_religious_rebel_growth = 0.01
	}
}


# =====================================================================
# The Kharaji Year (al-sana al-kharajiyya): the flood assessment
#
# Egypt's fiscal year runs on the Coptic solar calendar rather than the
# lunar one, because the assessment follows the inundation and the
# inundation does not follow the moon. Every regime since the conquest
# kept the Coptic months for the kharaj for that reason alone, and
# Egypt was still reckoning taxes by them in 1875. The column on Rawda
# island, rebuilt in 861, is read each summer; at sixteen cubits the
# canal is cut, the festival of the wafa is held and the year opens on
# a good assessment. A short flood is answered with remission written
# into the roll rather than collection enforced on a crop that never
# came up.
#
# Working: the roll matches the ground, the villages stay where they
# are, and prosperity is not spent recovering from an assessment made
# in the wrong year. Decayed: the lunar court year gains eleven days
# annually on the solar tax year, the treasury covers the gap by
# debasement, and families assessed on a flood that never arrived sell
# up and sink.
# =====================================================================
cpt_kharaji_year_bureaucracy = {
	implementation_price = price:implement_bureaucracy_price
	maintenance_price = price:maintain_bureaucracy_price
	removal_price = price:remove_bureaucracy_price
	maintenance_price_modifier = {
		value = country_economical_base
		multiply = 0.003
	}

	potential = {
		has_or_had_tag = CPT
		has_game_rule = nd_bureaucracies_enabled
	}

	# There is one gauge that sets the year and it stands on Rawda,
	# in the capital. The reading has to be ours and the column has to
	# have been rebuilt.
	allow = {
		owns = location:cairo
		has_advance = nd_cpt_house_of_the_flood_gauge
	}

	estates_that_like = {
		peasants_estate
		crown_estate
	}
	estates_that_dislike = {
		burghers_estate
	}

	# Granaries fill and empty on the same calendar the harvest keeps,
	# so less of the stored crop is lost between the two.
	neutral_modifier = {
		global_food_decay = -0.005
	}

	# Assessment taken from the column and the walked field, remission
	# granted in the short years, and a countryside that has no reason
	# to abandon its land before the collector arrives.
	positive_modifier = {
		scale = { value = scope:maintenance }
		global_monthly_rural_control = 0.003
		monthly_peasants_estate_rebel_growth = -0.002
		# Half of the base decay every country has (0.01 a month, vanilla
		# auto_modifiers/country.txt): the countryside is lost more slowly,
		# not never.
		global_prosperity_decay = -0.005
	}

	# The two calendars drift apart, the year is transferred and the
	# shortfall is met with debased coin, while the villages assessed
	# on last decade's rolls lose their land.
	negative_modifier = {
		scale = {
			value = 1
			subtract = scope:maintenance
		}
		monthly_inflation = 0.005
		global_pop_demotion_speed_modifier = 0.10
	}
}


# =====================================================================
# The Letters of the Zimam (huruf al-zimam): the accounting hand
#
# In the tenth century the accountants of Egypt cut Coptic uncials down
# into a fast curvilinear numeral set, huruf al-zimam, the letters of
# the registers. Estimates, rent rolls, audits and foliation were kept
# in it by Christians, Muslims and Jews alike for the next nine hundred
# years, and it was learned inside the secretarial families rather than
# in any school. This is the mechanism behind the Coptic hold on the
# fiscal bureaus that the Diwan of the Copts merely houses: clerks were
# dismissed from the dawawin at least nine times between 1280 and 1450
# and recalled every time, because the previous administration's books
# were unreadable to anyone not raised in the hand.
#
# Working: the state audits its own upkeep and its own household down
# to the tally, and the clerk families ride out every purge because
# they are always sent for again. Decayed: the hand becomes a closed
# racket, the families own the only copy of what the country is worth,
# and nobody outside will lend against paper drawn on books they
# cannot read.
# =====================================================================
cpt_zimam_ledgers_bureaucracy = {
	implementation_price = price:implement_bureaucracy_price
	maintenance_price = price:maintain_bureaucracy_price
	removal_price = price:remove_bureaucracy_price
	maintenance_price_modifier = {
		value = country_economical_base
		multiply = 0.003
	}

	potential = {
		has_or_had_tag = CPT
		has_game_rule = nd_bureaucracies_enabled
	}

	# The hand is taught in the revenue office, by the men who use it.
	# No diwan, no apprenticeship.
	allow = {
		has_advance = nd_cpt_diwan_of_the_copts
	}

	estates_that_like = {
		burghers_estate
	}
	estates_that_dislike = {
		nobles_estate
	}

	# Standing cost of the arrangement, paid whether or not the schools
	# are funded: an office held is an office the family keeps, and the
	# clerk houses convert appointment into standing.
	neutral_modifier = {
		burghers_estate_power_from_cabinet = 0.10
	}

	# Every upkeep tallied, every court account kept in a script that
	# cannot be padded, and a clerk class that survives its own
	# dismissals because it is always recalled.
	positive_modifier = {
		scale = { value = scope:maintenance }
		building_upkeep_efficiency = 0.15
		court_spending_efficiency = 0.10
		burghers_estate_satisfaction_recovery = 0.001
	}

	# The registers become the property of the men who write them, and
	# no foreign house will discount a bond secured on accounts its own
	# factors cannot audit.
	negative_modifier = {
		scale = {
			value = 1
			subtract = scope:maintenance
		}
		global_burghers_estate_power = 0.10
		bond_interest = 0.02
	}
}


# =====================================================================
# The Purse of the Arakhina: the lay notable houses
#
# The arakhina were the lay Coptic notables who farmed revenues, banked
# officials, and stood surety for everyone below them. They covered the
# shortfalls in the community's capitation, ransomed prisoners and paid
# for churches out of their own accounts, and the reason mattered:
# taxation was the chief engine of conversion in medieval Egypt, so a
# house that paid a poorer family's assessment was buying that family's
# continued existence as Copts. By the seventeenth and eighteenth
# centuries these houses held more practical authority over Coptic
# affairs than the patriarch did, and the quarrel over whether laymen
# or bishops should administer the endowments ran until a communal
# council settled it in 1874.
#
# Working: a treasury that borrows from its own congregation borrows
# deep and cheap, and families the assessment would have ruined stay
# where they are. Decayed: the money is private money, the bishops
# watch laymen run the endowments and stop cooperating, and the
# quarrel becomes the community's main business.
# =====================================================================
cpt_arakhina_purse_bureaucracy = {
	implementation_price = price:implement_bureaucracy_price
	maintenance_price = price:maintain_bureaucracy_price
	removal_price = price:remove_bureaucracy_price
	maintenance_price_modifier = {
		value = country_economical_base
		multiply = 0.003
	}

	potential = {
		has_or_had_tag = CPT
		has_game_rule = nd_bureaucracies_enabled
	}

	# The houses already exist on the day the country is formed. This
	# one costs nothing to reach and everything to keep.
	allow = {}

	estates_that_like = {
		burghers_estate
	}
	estates_that_dislike = {
		clergy_estate

	# The laymen who hold the purse hold the community's business, and

	# settled. This is the arrangement's actual price.
	neutral_modifier = {
		clergy_estate_blocked_from_cabinet = yes

	# Private houses stand behind the treasury, and the families a bad

	# clergy conduct their quarrel with the notables in public.
	negative_modifier = {
		scale = {
			value = 1
			subtract = scope:maintenance
		}
		clergy_estate_satisfaction_decay = 0.02
		monthly_clergy_estate_rebel_growth = 0.015
	}
}
