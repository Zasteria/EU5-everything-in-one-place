# ==========================================================================
# Francia (FRK): bureaucracies
# ==========================================================================
# Six institutions of the Carolingian realm that the heritage tree does not
# already carry (it has the missi, the capitularies, the palace and cathedral
# schools, the marches, the chamber court, the imperial circles, the
# Frankfurt fair and the Rhine commission). Two slots from the auto-modifier
# plus the capital's one: three of six.
#
# A Francia born of France keeps 99_nd_fra.txt, one born of Burgundy or
# Lotharingia keeps 99_nd_gbu.txt or 99_nd_lot.txt, so no institution and no
# modifier key here repeats those three files, vanilla byz.txt, or FRK's own
# advances, buildings and timed modifiers (checked 2026-09-10). Values sit
# near the vanilla median for their key unless a line says otherwise.
#
# Each estate is liked once and the crown twice; nobles and peasants are
# disliked twice. The pattern follows who held each institution, not balance.

# --------------------------------------------------------------------------
# Scabini (from about 780; the town echevins and Schoeffen until the 1790s)
# --------------------------------------------------------------------------
# Sworn judges of the county court who had to know every people's law, so
# the gate is the heritage Leges nationum. The later benches were the town
# patriciates (Metz, Aachen, Cologne), hence burghers like and nobles, whose
# own courts they displaced, dislike. Neglected, the bench closes into a
# caste; the longer it has sat, the more closed (entrenchment 1x to 2x).
# Recovery 0.001 is the only vanilla advance value for the burgher and
# peasant forms (culture_dalmatian.txt:260, government_monarchy.txt:19).
frk_scabini_bureaucracy = {
	implementation_price = price:implement_bureaucracy_price
	maintenance_price = price:maintain_bureaucracy_price
	removal_price = price:remove_bureaucracy_price
	maintenance_price_modifier = {
		value = country_economical_base
		multiply = 0.003
	}

	potential = {
		has_or_had_tag = FRK
		has_game_rule = nd_bureaucracies_enabled
	}

	allow = {
		has_advance = nd_frk_leges_nationum
	}

	estates_that_like = {
		burghers_estate
	}
	estates_that_dislike = {
		nobles_estate
	}

	neutral_modifier = {
		burghers_estate_satisfaction_recovery = 0.001
	}

	positive_modifier = {
		scale = { value = scope:maintenance }
		cultures_capacity_modifier = 0.15
		global_burghers_max_literacy = 5
	}

	negative_modifier = {
		scale = {
			value = 1
			subtract = scope:maintenance
			multiply = {
				value = 1
				add = { value = scope:entrenchment divide = 100 }
			}
		}
		base_burghers_estate_power_modifier = 0.1
	}
}

# --------------------------------------------------------------------------
# Precaria verbo regis (Estinnes 743; hereditary in practice by Quierzy 877)
# --------------------------------------------------------------------------

# monarchy: a republic has no king whose word binds the church. The
# benefices settled armed men across the countryside (rural nobles) and

# --------------------------------------------------------------------------

# --------------------------------------------------------------------------

# every parish (desired clergy) and made the church rich enough for the
# crown to tax in turn, as France's decimes and don gratuit did (clergy max
# tax). Neglected, lay lords take the tithe: the peasant pays it and has less
# left for the crown, and the preachers turn on it (the Twelve Articles of
# 1525). Not the vanilla papal tithe: that is gold sent to Rome, and no key
# of that mechanic is used here.

# --------------------------------------------------------------------------

# --------------------------------------------------------------------------

# 792 and 793, with royal grain sold under the tariff. The gate is Frankfurt,
# where it was proclaimed; the formation requires Frankfurt, so this only
# closes if the city is lost. Peasants like it and the grain dealers
# (burghers) do not. Neglected, the dealers hoard and the stored grain spoils.
