# Levies are chosen by total combat power: each pop raises the strongest
# levy it is eligible for, wherever the levy is written (EU5 1.4,
# common/levies/readme.txt). The numeric prefix of this file name decides
# nothing and is kept only so paths stay stable. Check a levy with
# eu5-validate --checks levies; scripts/fix_levy_power.py repairs one.
#
# The Tuareg levies draw TRIBESMEN, the only pop the heartland holds, and
# only Tuareg ones: the drum summons the tribes bound to it, not every
# nomad the country has conquered. Vanilla offers tribesmen a_tribesmen
# (0.469, never scales) and tribal camelry (0.678, only where the market
# produces camels), so each rung below must beat 0.678, not just 0.469.
# Do NOT pass these levies to fix_levy_power.py --place: its band is
# measured from a_tribesmen and would put them under tribal camelry.
