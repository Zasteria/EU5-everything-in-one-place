Quality of Life by Buddy - Changelog
=====================================

v1.1.0 (2026-09-23)
-------------------
- Changed: The "Watch Order of Chivalry cooldown" toggle in the CMF menu is now
  enabled by default when starting a new game. It can still be turned off.

v1.0.9 (2026-09-18)
-------------------
- Fixed: The CMF toggle for cabinet action alerts now uses the cabinet
  action icon instead of the red warning icon.

v1.0.8 (2026-09-18)
-------------------
- Added: The "Stabilize Country" and "Strengthen Government" cabinet
  actions no longer complete automatically when reaching the maximum.
  They stay active (keeping the reduced maintenance cost) and the player
  is alerted when the cap is reached, with a new alert toggle in the CMF
  menu (on by default).

v1.0.7 (2026-09-15)
--------------------
- Added: New "Non province capitals" option in the fort demolition location
  rank filter: only locations that are not the capital of a province are
  cleaned.

v1.0.1 (2026-08-19)
--------------------
- Fixed: Cooldown alerts for estate emergency interactions now work correctly.
  The cooldown type names in the watch list now match the vanilla cooldown
  identifiers (e.g. ask_for_extra_levies_cooldown).
  Affected interactions: Ask for Extra Levies, Levy Extraordinary Taxes,
  Request Clerical Endorsement, Request Noble Envoys, Request Emergency Grant,
  Appeal to the Commoners, Call the Tribes to Arms, Call Emergency Parliament.
