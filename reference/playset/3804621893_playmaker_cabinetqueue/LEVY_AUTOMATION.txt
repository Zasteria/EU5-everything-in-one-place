Levy automation

Default panel, bottom row:
- Army raise: native automatic army-levy raising at war.
- Navy raise: native automatic navy-levy raising at war.
- Peace dismiss: opt-in automatic dismissal of both types while fully at peace.

Raise controls directly mirror existing game settings; installing this change
does not alter them. Enable the desired raise controls and Peace dismiss.
Peace dismiss is off unless enabled. Turning it on while at peace also processes
levies already raised. Turning it off stops future dismissals and invalidates
old daily callbacks; it does not change the independent native raise settings.

Daily country callbacks request dismissal only when at_war = no. Persistent
country variables save the enabled state. The GUI workers also recheck peace,
enabled state, player ownership and raised levies immediately before dispatch.
Pending requests automatically open the military overview. Dispatch workers
are inside that view, where the engine supplies the UnitOverview data context.
They use UnitOverview.CanDisbandAllLevies and DisbandAllLevies for army/navy,
the same functions used by the vanilla military overview. No unit-destruction
effects are used. Regular troops and ships are not selected for removal.
Requests stay pending while native restrictions block dismissal and are renewed
daily after an attempt. The opener is outside the minimizable Default panel.
Blocked levies can cause the overview to reopen on the next daily request;
leave it open while waiting, or turn Peace dismiss off to suspend the automation.

Static checks passed: balanced blocks, resolved scripted GUI/localization keys,
native API names from game data-type logs, dismissal eligibility gates, and
generation checks that reject old callbacks after toggling off/on.

Fix after the first in-game test: error.log repeatedly reported "No context
supplied ... wanted context of type 'UnitOverview'" from the topbar worker.
All UnitOverview calls were removed from the topbar and moved into the native
unit_overview lateralview. Only the two workers were added to that view; its
original controls remain unchanged. Requests open the view at most once per
daily request. The game log records PMCQL|opening_military_overview and
PMCQL|army_native_dismiss_requested / navy_native_dismiss_requested for diagnosis.
Restart the game to load the new override; with Peace dismiss enabled, advance
one day at peace. For an immediate request, toggle Peace dismiss off then on.
