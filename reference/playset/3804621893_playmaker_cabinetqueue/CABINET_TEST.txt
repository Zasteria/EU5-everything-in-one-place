COMMUNALISM CABINET PROMOTION — 0.3.59
The test controls have been retired. Opening Setup > Communalism now grants the
existing guarded privileges, then uses the successful native cabinet selection
flow to promote Communalism in an idle slot. No member is hired. Existing tasks
are preserved. Repeated clicks skip the last assigned slot while it still has
the matching task. If all slots are busy, only the privilege preset is applied.
