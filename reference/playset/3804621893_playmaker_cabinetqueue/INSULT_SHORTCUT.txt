SEND INSULT SHORTCUT

The Declare War window now has Send an Insult to the left of Declare War.
It uses the native insult action on the selected recipient, with native eligibility
and cooldown checks. Clicking it auto-accepts the normal insult dialog, using the
native default insult. Other ways of sending insults retain their confirmation.

A transient UI request is consumed once by the insult dialog and expires after
three seconds if the dialog does not open. It is not saved in the campaign.

Modified UI files must be reloaded (restart the game if hot reload does not pick
them up). Static checks passed; actual click/position behavior needs in-game testing.
