Strengthened Faith scripted-grant comparison (experimental)

Use the same paused starting save without Strengthened Faith for BOTH runs.
1. Record government power/legitimacy and Clergy, Nobles, Burghers and Commoners
   satisfaction. Grant Strengthened Faith normally and confirm. Record the new
   values and whether the privilege has an implementation timer.
2. Reload the ORIGINAL save. Opening Setup > Script grant test. Record the same
   values and implementation behavior, without advancing time between readings.
3. Report differences. Do not use this test save as your main campaign until
   the consequences have been compared.

This button is independent of the Communalism sequence and affects only
Strengthened Faith. It cannot repeat in the same save after a valid attempt.
Country variables pmcqp_test_{power,clergy,nobles,burghers,peasants}_{before,after}
record the scripted path's measurements. PMCQ42 logs identify its outcome.
The test now applies Clergy satisfaction = privilege target satisfaction (5%)
times the game's grant multiplier (3). Other non-Crown estates receive the
privilege's power bonus (20%) times the game's penalty scale (-0.5) times their
pre-grant power share. This fits the supplied native tooltip and approximate
estate powers. Native equivalence still requires an in-game comparison.
