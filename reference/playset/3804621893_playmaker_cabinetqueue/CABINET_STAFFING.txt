SKILL-BASED CABINET STAFFING

Government outliner > STAFF: OFF/ON enables a saved, per-country daily selector.
It also scans immediately when switched on. It starts on automatically when
the game UI loads for a country that has not used this setting. A saved Off
choice is preserved across reloads.

Only empty cabinet slots with an assigned task are considered. The selector
reads the task's ADM/DIP/MIL type and appoints the eligible character with the
highest corresponding skill already in the country. Serving generals,
admirals and existing cabinet members are excluded. It does not hire advisers,
replace existing members, or change cabinet tasks. Slots without tasks stay
empty because there is no task skill to match. Multiple vacancies are handled
in cabinet iteration order; each appointment removes that adviser from the pool.

The country must be able to pay price:set_cabinet_member. That price is paid
only after the scripted appointment reports the selected member in the slot.
The daily callback is invalidated when switched off; rapid toggling does not
create additional active loops.

Economy no longer enables native cabinet-member automation. Enabling custom
staffing disables native cabinet-member automation and keeps it disabled while
custom staffing runs. Switching custom staffing off does not restore native
automation. Existing saves keep their native setting until changed in-game
or until custom staffing is enabled (including first-time default startup).

Validation: actual script logic passed simulated skill ranking, eligibility,
occupied/idle slot preservation, exhausted candidate pool, affordability,
failed appointment, repeat-charge, and stale-callback checks. Native eligibility,
appointment effects and prices are mocked. Verify appointments and actual
charges in-game after restarting; native equivalence is not runtime-confirmed.
