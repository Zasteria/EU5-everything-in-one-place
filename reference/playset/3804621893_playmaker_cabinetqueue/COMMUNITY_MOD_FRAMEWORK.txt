PLAYMAKER - COMMUNITY MOD FRAMEWORK

Enable Community Mod Framework (version 2.x) alongside this mod and restart EU5.
Press Esc, choose Mod Menu, then select Theplaymaker.

General
- Remove Forts opens a Yes/Cancel confirmation before destroying stockades,
  castles and city walls in all owned locations. Cancel or X makes no changes.
- Mouse Controls: Swap war-badge clicks (ON by default). ON uses left-click for
  peace and right-click for the war screen; OFF restores the normal clicks.
- Recommended Setup opens Economy, applies recommended settings, then closes it
  and returns to Theplaymaker > General in the Mod Menu.
  Includes skill staffing, auto army/navy levies, peacetime dismissal and Autostab.
- Notifications: Imperial Circle request suppression and notification suppression.
- Add land to HRE and the hold-to-confirm Dismantle HRE tool.

Diplomacy
Auto Gift (Experimental) sends direct gold transfers for 10 favors. OFF by default.
Open it, add targets, set a treasury reserve, then turn it ON. Run now checks
immediately (even while paused); monthly checks continue while enabled.
A saved ten-year per-target cooldown is preserved when removing/re-adding targets.
Native gift cooldowns block this tool, but its cooldown cannot block manual gifts.
No diplomat is required. The price is an experimental approximation; see AUTO_GIFT.txt.

Click Choose action for any of the six positions. The searchable picker reads the
live game diplomacy list, including the default war/CB actions and every exposed
category. It is not a fixed list of ten actions. Picking an action saves the shortcut
without executing it, even if it is currently unavailable. Context-specific actions
are listed when exposed by the game for the current campaign.
The choices are saved per campaign and can be changed while paused. Use Restore
original six to restore Send Gift, Buy Access, Food Access, Call to War, Alliance,
and Threaten War. Original access/alliance choices retain their End/Break behavior.
The cabinet and diplomacy shortcut rows always remain enabled.
Native costs, diplomat requirements, cooldowns and acceptance still apply.

Message Memory
- Enable Favorites System (Experimental): master switch, OFF by default.
  OFF hides event-option stars and disables automatic selection and popup hiding.
  Saved favorites are preserved. ON shows the stars beside event choices.
- Automatically choose remembered events: separate ON/OFF setting, OFF by default.
  Only runs while the master switch is ON.
- Event Favorites browser and installed preset loader.
  Loading a preset does not enable automatic selection.

The old Secret menu and population right-click launcher are removed.
Debug mode and Occupy War Enemies buttons are removed.
Preset save/load tool instructions now point to the framework menu.

Existing campaigns keep their notification choices and saved event favorites.
Automatic event selection starts OFF on first use of this integration; once enabled,
that preference persists in the campaign. Export/import favorites as before for
other campaigns. Framework shortcut settings are campaign-local.
