INTEGRATE ALL — 0.3.56
Government outliner ribbon > INT (Integrate All) switches the current cabinet slots to the mod's
existing Auto Integrate action. It replaces other tasks, includes empty slots,
preserves members, and skips slots already set or encouraging a societal value.
Culture Convert All also preserves slots encouraging a societal value.
Protected slots count as skipped. No characters are hired.
Each successful assignment is observed before the next slot is opened.
Unavailable or unconfirmed slots time out after 20 seconds and count as failed;
the next slot is then attempted. Normal native restrictions still apply.
Stop switching cancels subsequent operations, without undoing completed changes.
This is a one-shot operation; new cabinet slots are not watched automatically.
The native single-slot click was user-tested in 0.3.55. Bulk switching still
requires in-game verification, particularly replacing an existing action.

Government ribbon controls: INT = Integrate All; CUL = Culture Convert All.
Both expanded outliner layouts include the controls, with full tooltips.
Stop switching and assignment progress remain in Default.
Ribbon placement is statically checked; in-game visual/click verification pending.

Outliner action rows now show Integrating <province> or Assimilating <province>
from each cabinet slot's current target. Area actions show their current area.
The label updates as targets change and returns to the normal action name when
no target is assigned. Both full and compact layouts include target labels.
Static structure/API checks passed; in-game label rendering remains to verify.
