# CMF Ordered List Fix

Версия 0.1.0. Патч к обычному CMF 2.5.0, ниже CMF в списке загрузки.
Два одноимённых файла CMF взяты из эталона в репозитории. При обновлении CMF
сверить регистрации списков, эффекты показа, скрытия, обхода и перемещения строк.

В упорядоченных списках скрытые строки хранятся после видимых. Порядок внутри
обеих групп сохраняется. Новая видимая строка появляется внизу видимой части.
CMF использует эту границу для стрелки вниз и ПКМ «в конец».
Правка охватывает локальные и глобальные списки, статическую и динамическую
регистрацию. Пока мод перебирает строки через CMF, перестановка откладывается
до его выхода из общего обхода. Содержимое строк хранится по прежним ключам.
В игре пока не проверен.
