# `assimilate_primary` — брифинг (мод «Автоматика совета»)

**0.9.7 (10-13): своя автоматика совета.** Его просьба 12.10: галочка
в CMF, задания по списку приоритетов, только общие действия; в CMF «Доступные»
(галочка) → «Приоритет» (порядок) → «Тонкие настройки».

**0.6.0 в игре 10-12: раздача работает.** 0.7.0 и история — по ссылке внизу.

Как устроено (`tools/council.py`, собирает `tools/generate.py`):
- `POOL` — 23 строки (20 действий + Noblesse Oblige + дипусилия «неприязнь» + полная ассимиляция); порядок по умолчанию и пороги — **мои догадки**.
- Галочка выключает игровой «Совет» и сразу раздаёт места.
- **Раздача** (`bag_asp_plan`, работает с 0.6.0): сверху вниз по «Приоритету»,
  своё место действие сохраняет, свободные берёт лучший по навыку. Подробно —
  в архиве ниже.
- **Пересчёт (0.9.3)**: полная раздача каждый месяц, при смене списков и новом
  советнике; действие переезжает к лучшему по навыку. Подробно — в архиве.
- Месяц — `cmf_monthly_human_country_pulse`; строки мода в `debug.log` — `bag_asp:`.
- **Ассимиляция — две строки (0.9.2–0.9.4, его правила 13.10)**: «до 50 %» идёт
  по статусам районов (`bag_asp_needs_half`: `integration_level = integrated`,
  или `conquered` без половины основной/признанной; на половине интегрированный
  становится `core` — «Национальный»). Порядок (0.9.5, script_values):
  сначала ступень среднего контроля по 10 пунктов (`bag_asp_control_band`;
  контроль 0 — только при ускорении, свободном месте и подходящем действии
  контроля, `bag_asp_control_reachable`, 0.9.6), внутри — `bag_asp_half_need` (интегрированный 100,
  завоёванный 1). В полной раздаче идущая ассимиляция **переезжает** туда,
  где `bag_asp_half_rank` больше (районы ассимилируются порознь). Место освобождается, когда районов не осталось,
  если «полная» (`promote_culture_full`) не в деле. Ускорение — работает.
- **Пара при нехватке мест (0.9.7, его прогон 13.10 07:12)**: `bag_asp_keep_pairs`
  идёт по ассимиляциям от лучшей провинции (`bag_asp_seat_rank`); если свободного
  места нет, слабейшая ожидающая уступает его контролю лучшей — только в полной
  раздаче и где действие контроля подходит (`bag_asp_control_fits`).
- **Зонды 0.9.7** (`bag_asp_probe_*`, `bag_asp: probe:`): порядок, места после
  прохода, провинции от 40 % без ассимиляции. Убрать, когда ответят.
- Интеграция и экстренное восстановление (в игре работает 10-12) — в архиве ниже.

**Не проверено:** 0.9.2–0.9.7 (0.9.4 — перескок — работает, 01:40); `(this)` как аргумент в `order_by`; нужен ли советнику обращения веры цели; «без `allow_multiple` — одно место» — догадка. Работает ли `order_by = cabinet_member.mil`; порядок `INTEGRATION`;
`order_by = { value = 1 subtract = satisfaction }`; замок места не виден
(`docs/research/vanilla.md`).
