# `assimilate_primary` — брифинг (мод «Автоматика совета»)

**0.5.0 (10-12): своя автоматика совета, скелет.** Его просьба 12.10:
галочка в CMF — и раз в какое-то время пустые места получают задания по
списку приоритетов, приближённому к ванили; только общие действия (ни
московских приказов, ни «заселения приграничья»); в CMF котёл → «Доступные»
(галочка «Использовать») → «Приоритет» (порядок). Дальше — тонкие настройки.

Как устроено (`tools/council.py`, собирает `tools/generate.py`):
- `POOL` — 20 действий в порядке по умолчанию; порядок и пороги
  (`stability < 50`, `inflation > 0`) — **мои догадки**, ваниль считает
  оценку 62 из 74 действий в движке.
- Галочка «Своя автоматика совета» выключает игровой «Совет»
  (`set_automated_system cabinet`) — иначе две автоматики делят одни места.
  «Члены совета» не трогаются.
- Раз в `period` мес. каждое место с советником и без действия получает первое
  действие сверху «Приоритета», которое отмечено, разрешено
  (`is_available_for`) и имеет цель. Цель проверяется **копией `visible` и
  `enabled` самого действия** из его `select_trigger`; триггеры «другое место
  уже делает это» сравнивают с `root`, у нас это страна — генератор заменяет
  их переменной `bag_asp_busy_<действие>` на занятых целях (ставится и
  снимается за проход).
- Раз в `review` мес. (0 — никогда) действия без `is_finished` снимаются и
  выбираются заново: сами они место не освобождают. Сроков внедрения у них
  нет, снятие ничего не теряет.
- Ассимиляция — в основную культуру; провинции, где признанная ведёт на 30
  п. п., не трогаются.
- Каждое назначение — `bag_asp: seat set to <действие>` в `debug.log`; пустое
  место — `bag_asp: a seat stays empty…`.

**Не проверено (всё 0.5.0):** берёт ли `set_cabinet_action` цели под их
`target_flag` (`selected_province`, `target_1`, `target_religion`… — ваниль
зовёт его только с `target`); освобождает ли место законченное действие;
считаются ли `"culture_percentage(dominant_culture)"` и
`order_by = { value = 1 subtract = satisfaction }`; рисуется ли список
«Приоритет» с одним текстовым полем; замок места наша автоматика не видит
(`docs/research/vanilla.md`).

Правило основной культуры для **игровой** автоматики (копия
`promote_culture.txt` с условием в `enabled`, порог `LEAD`) и история 0.1–0.4 —
[`docs/archive/assimilate_primary_history.md`](../../docs/archive/assimilate_primary_history.md).
