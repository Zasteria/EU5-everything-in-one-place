# `assimilate_primary` — брифинг (мод «Автоматика совета»)

**0.9.0 (10-12): своя автоматика совета.** Его просьба 12.10: галочка
в CMF, задания по списку приоритетов, только общие действия; в CMF «Доступные»
(галочка) → «Приоритет» (порядок) → «Тонкие настройки».

**0.6.0 в игре 10-12: раздача работает.** 0.7.0 и история — по ссылке внизу.

Как устроено (`tools/council.py`, собирает `tools/generate.py`):
- `POOL` — 22 строки (20 действий + Noblesse Oblige + дипусилия «неприязнь»); порядок по умолчанию и пороги — **мои догадки**.
- Галочка выключает игровой «Совет» (`cabinet`) и сразу раздаёт все места.
- **Раздача** (`bag_asp_plan`, работает с 0.6.0): сверху вниз по «Приоритету»,
  своё место действие сохраняет, свободные берёт лучший по навыку. Подробно —
  в архиве ниже.
- Месяц — `cmf_monthly_human_country_pulse`. В `debug.log`: `bag_asp: month`,
  `handing out every seat` / `filling empty seats`, `seat set to <действие>`.
- **0.9.0, его список 12.10** (в игре не проверено): `POOL` дописан в конец
  (CMF держит строки по номеру): Noblesse Oblige (строка видна по
  `is_visible_for`) и вторая строка дипусилий «неприязнь» (`ROW_ACTION`;
  место только при `has_countries_with_(near_)coalition_grade_antagonism`).
  «Тонкие настройки» — группы CMF: цель ассимиляции (основная / самая
  распространённая признанная, `culture_percentage_in_country(this)`), цель
  обращения (государственная / другая той же группы), «Ускорять контролем»
  (`bag_asp_speedup`: в провинцию ассимиляции Noblesse Oblige, иначе повышение
  контроля — игра оба в одну не даёт). Строка 23 списка настроек — **замер
  сдвига ценностей**: `GetVariable('bag_asp_sv_cab').GetCabinet.<…>` — предел,
  всего, инерция, за месяц у советника на этом действии.
- Интеграция и экстренное восстановление (в игре работает 10-12) — в архиве ниже.

**Не проверено:** держит ли переменная скоуп места (`bag_asp_sv_cab`); `(this)` как аргумент в `order_by`; нужен ли советнику обращения веры цели; «без `allow_multiple` — одно место» — моя догадка (у повышения контроля `visible` проверяет ту же цель на другом месте, значит, мест может быть несколько). Берёт ли `set_cabinet_action` цели под их
`target_flag` (`selected_province`, `target_1`, `target_religion`… — ваниль
зовёт его только с `target`; с `target` берёт — интеграция, 10-12); работает
ли `order_by = cabinet_member.mil`; порядок `INTEGRATION`;
`order_by = { value = 1 subtract = satisfaction }`; замок места наша
автоматика не видит (`docs/research/vanilla.md`) — запертое место она тоже
переназначит.

`promote_culture.txt` с условием в `enabled`, порог `LEAD`) и история 0.1–0.4 —
[`docs/archive/assimilate_primary_history.md`](../../docs/archive/assimilate_primary_history.md).
