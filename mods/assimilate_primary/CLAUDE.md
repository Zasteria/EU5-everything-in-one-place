# `assimilate_primary` — брифинг (мод «Автоматика совета»)

**0.9.6 (10-13): своя автоматика совета.** Его просьба 12.10: галочка
в CMF, задания по списку приоритетов, только общие действия; в CMF «Доступные»
(галочка) → «Приоритет» (порядок) → «Тонкие настройки».

**0.6.0 в игре 10-12: раздача работает.** 0.7.0 и история — по ссылке внизу.

Как устроено (`tools/council.py`, собирает `tools/generate.py`):
- `POOL` — 23 строки (20 действий + Noblesse Oblige + дипусилия «неприязнь» + полная ассимиляция); порядок по умолчанию и пороги — **мои догадки**.
- Галочка выключает игровой «Совет» (`cabinet`) и сразу раздаёт все места.
- **Раздача** (`bag_asp_plan`, работает с 0.6.0): сверху вниз по «Приоритету»,
  своё место действие сохраняет, свободные берёт лучший по навыку. Подробно —
  в архиве ниже.
- **Пересчёт (0.9.3, его правило 13.10)**: полная раздача по умолчанию
  каждый месяц (`review` = 1), сразу при смене списков (`_on_changed`) и при
  новом советнике (`on_cabinet_assigned`, лист сливается с игровым). В полной
  раздаче строка переносит своё действие с целями к лучшему по навыку
  свободному советнику (`bag_asp_move_<row>`); сохраняет ли игра прогресс при
  переносе — не мерено.
- Месяц — `cmf_monthly_human_country_pulse`. В `debug.log`: `bag_asp: month`,
  `handing out every seat` / `filling empty seats`, `seat set to <действие>`.
- **0.9.0–0.9.1**: Noblesse Oblige, дипусилия «неприязнь», «Тонкие настройки» —
  группы CMF; ускорение контролем (`bag_asp_pair`) — подробно в архиве.
- **Ассимиляция — две строки (0.9.2–0.9.4, его правила 13.10)**: «до 50 %» идёт
  по статусам районов (`bag_asp_needs_half`: `integration_level = integrated`,
  или `conquered` без половины основной/признанной; на половине интегрированный
  становится `core` — «Национальный»). Порядок (0.9.5, script_values):
  сначала ступень среднего контроля по 10 пунктов (`bag_asp_control_band`;
  контроль 0 — только при ускорении, свободном месте и подходящем действии
  контроля, `bag_asp_control_reachable`, 0.9.6), внутри — `bag_asp_half_need` (интегрированный 100,
  завоёванный 1). В полной раздаче идущая ассимиляция **переезжает** туда,
  где `bag_asp_half_rank` больше (районы ассимилируются порознь). Место освобождается, когда районов не осталось,
  если «полная» (`promote_culture_full`) не в деле. Ускорение — работает.
- Интеграция и экстренное восстановление (в игре работает 10-12) — в архиве ниже.

**Не проверено:** 0.9.2–0.9.6; `(this)` как аргумент в `order_by`; нужен ли советнику обращения веры цели; «без `allow_multiple` — одно место» — моя догадка (у повышения контроля `visible` проверяет ту же цель на другом месте, значит, мест может быть несколько). Работает ли `order_by = cabinet_member.mil`; порядок `INTEGRATION`;
`order_by = { value = 1 subtract = satisfaction }`; замок места наша
автоматика не видит (`docs/research/vanilla.md`) — запертое место она тоже
переназначит.

Правило основной культуры для **игровой** автоматики (копия
`promote_culture.txt` с условием в `enabled`, порог `LEAD`) и история 0.1–0.4 —
[`docs/archive/assimilate_primary_history.md`](../../docs/archive/assimilate_primary_history.md).
