# `assimilate_primary` — брифинг (мод «Автоматика совета»)

**0.9.1 (10-13): своя автоматика совета.** Его просьба 12.10: галочка
в CMF, задания по списку приоритетов, только общие действия; в CMF «Доступные»
(галочка) → «Приоритет» (порядок) → «Тонкие настройки».

**0.6.0 в игре 10-12: раздача работает.** 0.7.0 и история — по ссылке внизу.

Как устроено (`tools/council.py`, собирает `tools/generate.py`):
- `POOL` — 22 строки (20 действий + Noblesse Oblige + дипусилия «неприязнь»); порядок по умолчанию и пороги — **мои догадки**.
- Галочка выключает игровой «Совет» (`cabinet`) и сразу раздаёт все места.
- **Раздача** (`bag_asp_plan`, работает с 0.6.0): сверху вниз по «Приоритету»,
  своё место действие сохраняет, свободные берёт лучший по навыку. Подробно —
  в архиве ниже.
- Месяц — `cmf_monthly_human_country_pulse`. В `debug.log`: `bag_asp: month`,
  `handing out every seat` / `filling empty seats`, `seat set to <действие>`.
- **0.9.0–0.9.1, его список 12.10 и правка 13.10**: `POOL` дописан в конец
  (CMF держит строки по номеру): Noblesse Oblige (видна по `is_visible_for`) и
  дипусилия «неприязнь» (`ROW_ACTION`; только при
  `has_countries_with_(near_)coalition_grade_antagonism`). «Тонкие настройки» —
  только группы CMF (список строк убран, его слово 13.10): цель ассимиляции
  (основная / признанная), цель обращения (государственная / другая той же
  группы), «Ускорять контролем». **Ускорение (0.9.1)**: за каждой ассимиляцией
  сразу её место контроля (`bag_asp_pair`: Noblesse Oblige, иначе повышение
  контроля), привязано к ней (`bag_asp_paired` у советника), в «Экстренном»
  считается её рангом, снимается вместе с ней (`bag_asp_unpair`). 0.9.0 ставил
  пару после всех ассимиляций — мест не осталось (13.10). Замер ценностей
  читался (TESTLOG 13.10), убран вместе со списком.
- Интеграция и экстренное восстановление (в игре работает 10-12) — в архиве ниже.

**Не проверено:** всё 0.9.1; откуда поток `promote_culture_action_progress` 13.10 (зонд `an assimilation seat has no province or no culture`); `(this)` как аргумент в `order_by`; нужен ли советнику обращения веры цели; «без `allow_multiple` — одно место» — моя догадка (у повышения контроля `visible` проверяет ту же цель на другом месте, значит, мест может быть несколько). Берёт ли `set_cabinet_action` цели под их
`target_flag` (`selected_province`, `target_1`, `target_religion`… — ваниль
зовёт его только с `target`; с `target` берёт — интеграция, 10-12); работает
ли `order_by = cabinet_member.mil`; порядок `INTEGRATION`;
`order_by = { value = 1 subtract = satisfaction }`; замок места наша
автоматика не видит (`docs/research/vanilla.md`) — запертое место она тоже
переназначит.
