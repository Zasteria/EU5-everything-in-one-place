# speed_5 — дневные скорости

Версия 0.1.1 для EU5 1.4.9. Мод задаёт паузы между днями в NGame.GAME_SPEED_TICKS_DAILY. Для скоростей с первой по пятую это 1 / 0,25 / 0,15 / 0,1 / 0 секунд, к ним прибавляется время расчёта дня. При нуле скорость ограничивает сам расчёт.

Почасовое правило использует таблицу игры. Переключить шаг времени в одиночной партии можно на паузе после начала игры. Настройки defines загружаются при старте. Производительность в партии ещё не проверялась.

    python tools/check_script.py mods/speed_5
