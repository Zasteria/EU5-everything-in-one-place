# `nmt_fix` — брифинг

Починка **National Mission Trees** (`national_mission_trees`): задания, которые
пишут «N районов у нас или у наших подданных», земли подданных не считали.

**Состояние: 0.2.0 (10-03), в игре не был ни 0.1, ни 0.2.** Нашлось 2026-09-29 на Болгарии:
«Завоевать Валахию», вся область у вассала, «Отвечающих этому требованию: 0».

**Причина.** База пишет `any_owned_location = { area = … OR = { owner = root
owner = { is_subject_of = root } } count >= N }`, а `any_owned_location`
перебирает только районы самой державы: половина `OR` про подданного не видит
ни одного района. Рабочую форму автор сам написал в шведском дереве
(`swe_stormaktstiden_mission_pack.txt`, `region:… = { any_location_in_region =
{ … owner ?= … } }`), её сборщик и ставит.

**111 условий**: 105 с одной областью или регионом переписаны в
`area:X = { any_location_in_area = { … } }`. Шесть не укладываются в один
`count` и сравнивают скриптовое значение (`in_game/common/script_values/`) под
`custom_tooltip` со своей строкой: четыре — по всей карте (`num_locations` свои
плюс каждого подданного; Богемия, Бранденбург, Эфиопия, Габсбурги), два
тевтонских — по двум областям или регионам сразу.

**Порядок загрузки: после National Mission Trees.** Файл заданий заменяет
базовый целиком по имени, поэтому пишутся только файлы с правками (21 из 40).
Обновится база — пересобрать, иначе мод вернёт её старую редакцию этих файлов.

## Под игру 1.4 (0.2.0)

National Mission Trees под 1.4 автор не обновлял (0.2 под 1.3.10). Сверка
10-03: все имена, которые NMT зовёт, против файлов игры до и после патча, плюс
ссылки `location:`/`area:`/`culture:`/… против того, что игра определяет.
`PATCHES` в сборщике, у каждой правки причина:

- **1.4 убрала:** событие `flavor_ara.6` (задание Арагона «Война ременсов»
  ждало его вечно — теперь ждёт решения `ara_sindicat_remenca_decision`, флаг
  или привилегию), модификатор
  `global_trade_through_owned_territory_efficiency` (Айюбиды, Брабант →
  `trade_land_efficiency`, как сама игра заменила его 0.10),
  `overlord_protects_other_subjects` у двух типов подданных.
- **Ошибки самого NMT, на 1.3 тоже:** казус белли венгерского «Подготовка
  крестового похода» не существовал и выдавался соседу на самого себя
  (→ `cb_crusade` у нас на соседа); кастильский «Меч Кастилии» давал казус
  белли владельцам Кастилии и Леона на нас (развёрнут, как в каролингском
  дереве у того же автора); `country_type:colonial`, `region:india`,
  `culture:byzantine_culture`, `location:goteborg` (текст задания — Варберг),
  `religion:reformed` (→ `calvinist`).

Не проверено и проверить отсюда нельзя: значок `arte_della_lana` (флорентийское
и савойское задания) больше не значок ни одного улучшения в 1.4; файла картинок
в `reference/` нет.

    python3 mods/nmt_fix/tools/generate.py     собрать (в tools/refresh.py)
