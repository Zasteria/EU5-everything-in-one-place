# `nmt_fix` — брифинг

Починка **National Mission Trees** (`national_mission_trees`): задания, которые
пишут «N районов у нас или у наших подданных», земли подданных не считали.

**Состояние: 0.1.0, в игре не был.** Нашлось 2026-09-29 на Болгарии:
«Завоевать Валахию», вся область у вассала, «Отвечающих этому требованию: 0».

**Причина.** База пишет `any_owned_location = { area = … OR = { owner = root
owner = { is_subject_of = root } } count >= N }`, а `any_owned_location`
перебирает только районы самой державы: половина `OR` про подданного не видит
ни одного района. Рабочую форму автор сам написал в шведском дереве
(`swe_stormaktstiden_mission_pack.txt`, `region:… = { any_location_in_region =
{ … owner ?= … } }`), её сборщик и ставит.

**111 условий**: 105 с одной областью или регионом переписаны в
`area:X = { any_location_in_area = { … } }`. Шесть не укладываются в один
`count` и сравнивают скриптовое значение (`in_game/common/script_values/`) под
`custom_tooltip` со своей строкой: четыре — по всей карте (`num_locations` свои
плюс каждого подданного; Богемия, Бранденбург, Эфиопия, Габсбурги), два
тевтонских — по двум областям или регионам сразу.

**Порядок загрузки: после National Mission Trees.** Файл заданий заменяет
базовый целиком по имени, поэтому пишутся только файлы с правками (21 из 40).
Обновится база — пересобрать, иначе мод вернёт её старую редакцию этих файлов.

## Команда

    python3 mods/nmt_fix/tools/generate.py     собрать (в tools/refresh.py)

Дерево под `in_game/` и `main_menu/` производное, руками не править. Блок
незнакомой формы сборщик не пишет, а называет файл и строку.
