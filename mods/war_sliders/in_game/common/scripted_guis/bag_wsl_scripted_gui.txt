# Кнопки зонда пишут одно число — цель ползунка, — а ползунок читает его
# привязкой `FixedPointToFloat(...GetVariable('bag_wsl_target').GetValue)`.
# Это и есть проверяемый привод: **мод меняет число, виджет едет за числом**.
# Через `AddScope` число не передать (скоуп — это объект), поэтому на каждое
# значение свой вход; в рабочем моде их заменит одна запись из скрипта.
