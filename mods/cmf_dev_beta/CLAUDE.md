# `cmf_dev_beta` — брифинг

**Заплатка к CMF Dev под бету 10-01, не копия.** 16 файлов CMF Dev по его же
путям; грузится после CMF Dev (зависимость) и подменяет их. Собирается:

    python3 mods/cmf_dev_beta/tools/port_from_cmf_dev.py

CMF держит копии ванильных типов окон (`gui/vanilla/cmf_*`, лобби, меню паузы);
тип, объявленный позже, побеждает, и 75 типов беты стояли в версии 1.3.
`tools/beta_types.json` — замеренный список: 69 дословных копий 1.3, пять типов
лобби (у CMF там только смена ключа подсказки — снята), меню паузы (кнопка меню
CMF возвращается после кнопок беты). Лобби — файл беты плюс ряд баннеров модов
CMF. **Тип, который CMF правил ради своей кнопки, в список не вносить** —
кнопка пропадёт. Механизм `beta_type` — `mods/cm_dev_perf/tools/beta_windows.py`.

`check_script.py` даёт 17 находок, все в телах беты (`flowcontainer`, `}}`):
ванильные, игра их же везёт.

**Собран 10-01, в игре не был.** Убрать, когда автор обновит CMF Dev.
