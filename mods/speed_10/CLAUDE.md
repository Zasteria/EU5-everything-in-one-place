# `speed_10` — проба десяти скоростей

**0.1.4 (10-06).** 0.1.0 в игре 10-06: десять скоростей работают, кнопки
рисуются как надо. На 0.1.1 (7 = 0.2, 8 = 0.15, 9 = 0.1): 0.2 медленно, 0.15
быстровато, 0.1 «бешеная» (сначала он назвал 8-ю и 9-ю, потом поправил).
0.1.4, его числа: 2.0 / 1.0 / 0.5 / 0.25 / 0.2 / 0.175 / 0.15 / 0.125 / 0.1 / 0,
в игре не был.
Число скоростей = длина таблиц
`GAME_SPEED_TICKS` и `GAME_SPEED_SCALES` (в 1.3 обе по 7 — 7 скоростей, в 1.4
по 5 — 5). Мод даёт обе по 10 и копию `hud_topbar.gui` с кнопками 6–10 (ширина
блока 105 → 210, кнопка 21).

- Ставится вместо Responsive Universalis и `speed_5` (та же таблица).
- `hud_topbar.gui` — копия ванильного файла беты: **после обновления игры
  пересобрать** (взять новый ванильный и вставить блоки `# SPEED 6..10`).

    python3 tools/check_script.py mods/speed_10
