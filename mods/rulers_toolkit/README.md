# `rulers_toolkit` — устройство

## Ползунки после войны (бывший `war_sliders`, 0.2.0, его просьба 10-18)

Файлы `bag_wsl_*` скопированы как есть; **устройство и всё купленное —
[`../war_sliders/README.md`](../war_sliders/README.md)**. Сменилось только CMF:
вкладка `war` страницы `bag_rtk`, ключи `bag_rtk__wsl_<id>` (были `bag_wsl__<id>`),
`_on_changed` кнопки — `bag_rtk__wsl_run_now_on_changed`; регистрация и обратный
звонок зовутся из `bag_rtk_*`. Переменные, окна, события, кнопка панели
`bag_wsl_run` — прежние. **С War Sliders вместе не ставить** — одни имена.
Настройки War Sliders в старом сейве не переносятся (новые ключи).

**0.2.1 (его просьба 10-18): два промаха последнего шага — чеканка в ноль.**
Месяц, который по прогнозу кончал правку (`bag_wsl_mint_final`, цель выше
пола), а инфляция всё выше цели — промах (`bag_wsl_mint_count_miss`): золото в
конце месяца сдвигает инфляцию. После двух — `bag_wsl_mint_force`, цель 0 до
конца правки. Зонд: `bag_wsl: the last step missed`, `…two misses, minting to
zero` в `debug.log`. В игре не было.
