# `rulers_toolkit` — брифинг

**Сборник мелкой автоматики для страны игрока** (его решение 10-18: «не хочется
плодить микромоды»). «Помощник правителя» / «Ruler's Toolkit», id
`bag.rulers_toolkit`, префикс `bag_rtk_`, нужен CMF. Одна вкладка CMF, по
группе на функцию; месячный такт один — `bag_rtk_monthly`
(`cmf_monthly_human_country_pulse`, только игрок), новая функция дописывает туда
строку. Кандидаты на перенос сюда: `war_sliders`, автоматика совета из
`assimilate_primary`, своё из `auto_marry`.

## 0.1.1 (10-18) — командиры из правителей

0.1.0 в игре 10-18 не назначил никого: `is_mercenary` — триггер полка, условие
армии было ложным (`docs/TESTLOG.md`). 0.1.1:

- **Мир:** раз в месяц до 20 шагов; шаг — первый в очереди свободный правитель
  (`crown_estate`, «Правители»; правитель первым, потом `mil`; не в совете, ничем
  не командует, `is_eligible_military_leader`) встаёт на самый большой отряд без
  правителя. **Ветвь — где отрядов меньше** (`bag_rtk_navy_pays_more`, счётчики
  `bag_rtk_n_army`/`_n_navy`; поровну — армия): власть от командования армиями и
  флотами — два котла по 25 % (`BASE_ESTATE_POWER_FROM_COMMAND`), каждый делится
  между командирами ветви (его слова; делится поровну или по размеру — не мерено).
  Отряд с правителем не трогаем. Чисто наёмный, изгнанный, в бою — мимо.
  Флоты — галочка `cmd_fleets`, по умолчанию вкл. (новый id: в старом сейве
  `cmd_navy` стоял выкл.).
- **Война:** при «Генерал-правитель» правитель без отряда — на самую большую армию.
- **Зонд:** `bag_rtk: month, peace pass` (настройка включена, мир),
  `bag_rtk: crown commander set` на каждое назначение.

## Что не проверено

- Видит ли следующий шаг, что прошлый кандидат уже `is_general` (иначе один
  человек пройдёт по всем отрядам: 20 строк «set» за месяц).
- Котлы: делятся ли поровну или по размеру отряда, и считаются ли отряды без
  командира.
