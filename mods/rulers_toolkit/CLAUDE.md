# `rulers_toolkit` — брифинг

**Сборник мелкой автоматики для страны игрока** (его решение 10-18: «не хочется
плодить микромоды»). «Помощник правителя» / «Ruler's Toolkit», id
`bag.rulers_toolkit`, префикс `bag_rtk_`, нужен CMF. Месячный такт один —
`bag_rtk_monthly` (`cmf_monthly_human_country_pulse`, только игрок), новая
функция дописывает туда строку.

## Командиры из правителей (работает на армиях, 10-18)

Как устроено (очередь, котлы армий и флотов, кого не трогаем) —
[`README.md`](README.md#командиры-из-правителей). Зонды `bag_rtk: month, peace
pass`, `bag_rtk: crown commander set`.

## Пленники

- **Выкуп после мира** (`bag_rtk_prisoners.txt`, в игре не смотрен): 1-го числа в мире, как
  ванильный `ransom_prisoners_effect`. Зонд `bag_rtk: prisoners offered for ransom`.
- **Генерала с пленных не снимаем**: «Замена генералов» ставит нового сразу,
  выключается только на всю страну; он выбрал оставить (10-18).
- **В тыл** (`bag_rtk_safety`, не больше двух раз на отряд): **в игре 10-18
  работает** (после боя, затем 1-го числа).
- **Своей точки и слияния скриптом нет** — чем проверено:
  [`rulers_toolkit_history.md`](../../docs/archive/rulers_toolkit_history.md).

## Напоминалка об откатах (0.6.5; вкладка `cooldowns` «Перезарядки»)

Как устроено — [`README.md`](README.md#напоминалка-об-откатах); генератор
`tools/gen_cooldowns.py`, после патча перегенерировать. **В игре 10-19:** 0.6.1 —
подвкладки и религия у католика; 0.6.3 — сословия по строке на сословие.
0.6.4 — подпись «Привлечь чужеземного» верна, но без галочки (нет владельца строки);
остальное «на первый взгляд в порядке». **Не мерено 0.6.5:** галочка этой строки;
зонд `list … rebuilt`; сословный зонд `estate action closed`.
Строки не переставлять и не убирать (галочка — по номеру строки): иначе новый
`setting_id`; генератор сверяет с `tools/cd_lists.json` и сам остановится.

## Женитьба династии (0.8.1; вкладка `family`, по умолчанию выкл.)

Его просьба 10-19 — [`README.md`](README.md#женитьба-династии). Прямой
`marry_character`, младшие первыми, невеста — родня монарха в дипдистанции.
**В игре без игрока 10-20 (его румынский сейв):** женит; династического брака
между странами скрипт создать не может (`royal_marriage` через
`perform_diplomatic_action` и `create_relation` молчат). 0.8.0 женил Вука на
Фуггерах. **Не мерено им самим** в обычной игре.

## Мир: шаблон договора и дипрепутация (0.9.x, его просьба 10-20)

Копия ванильного `gui/peace_offer_view.gui` (после патча — `tools/rebase_overrides.py`).
- **Дипрепутация** (кнопка у сброса): ползунок «Дипломатия» на максимум — свой
  ползунок на том же `MaintenanceSetting` (`gui/bag_rtk_rep_driver.gui`, как у
  ползунков после войны), советник с лучшей дипломатией на `diplomatic_endeavors`;
  назад — второе нажатие, отправка договора (через 0.1 с) или 1-е число.
  **Работает в игре 10-20** (1.4.2), кроме: советник не возвращается на прежнее
  действие (кресло пустеет — по замыслу). Действие, поставленное скриптом без
  `actor`, сыпало в лог `diplomatic_endeavors_action_progress` ~140 раз в секунду
  (280 МБ за сессию) — в 0.9.4 `set_cabinet_action … actor = root`, не проверено.
- **Шаблон** (`tools/gen_peace.py`): CMF «Мир» — приоритет 0–9 на пункт; кнопка
  сбрасывает договор, шагомер идёт по приоритетам, помощники жмут
  `PeaceTreaty.OnClick` пунктам, узнанным по куску `GetShortName` (типа окно не
  отдаёт — зонд 10-20), золото — «+». **0.9.3 в игре 10-20: шаги шли, ни один
  пункт не нажат.** 0.9.4: помощники вынесены из кнопки в начало панели,
  приоритеты по умолчанию, зонд нажатий (`peace template, a term clicked`). Не проверено.

## 0.9.12–0.9.13 (10-21, не проверено)

- **Шаблон мира 0.9.12:** проверка «хватает очков» была на `IntToFixedPoint` (отдаёт float) —
  падала молча на каждом пункте (лог 10-20, 108 768 строк); теперь `FixedPointToInt`/`_int32`.
- **Напоминалка:** напоминание приходит, когда действие можно сделать (`bag_rtk_cd_ready_<тип>` —
  ворота + `allow` действия + `READY_EXTRA`, напр. орден, которому можно дать владение); пока
  нельзя — ждёт. Строка недоступного действия прячется, даже отмеченная (раскол кончился, 10-20).
- **Нерегулярные полки после боя 0.9.13** (его просьба 10-20, `merge_irregulars`, вкл.): бой
  (`on_battle_won`/`lost`) ставит `bag_rtk_merge_due`, привод `gui/bag_rtk_merge_driver.gui` жмёт
  пункт меню отряда «Объединить иррегулярные полки» (`UnitActionItem.SingleLeftClick`) у армий
  из `AccessPlayerUnits`; пункт узнаётся по `GetKey` (`non_regular`) или имени. Ключ не мерен.

## 0.9.19 (10-24, сборка 26142040, не проверено)

- Копия `peace_offer_view.gui` взяла правки патча (`tools/rebase_overrides.py`, без конфликтов):
  вложенные пункты мира теперь по `UsesNestedTreaties`, не `IsSeizeLand`, — иначе новый пункт

  по-прежнему выключено (0.9.18).
