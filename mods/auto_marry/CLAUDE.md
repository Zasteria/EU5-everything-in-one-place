# `auto_marry` — брифинг

**Nobles Auto Marry - Continued (мастерская 3681629733) под 1.4, с русским
текстом. Полная копия, ставится ВМЕСТО оригинала.** Сохранение подхватывает:
переменные, ситуация и события названы как у автора.

    python3 mods/auto_marry/tools/generate.py     собрать (в tools/refresh.py)

Всё под `in_game/` и `main_menu/` производное, кроме
`main_menu/localization/russian/` — его пишем руками, сборщик его не трогает.

## Сверка с 1.4 (10-06)

Всё, что зовёт мод, есть в дампах и файлах беты 10-01;
`character_can_marry_trigger` в 1.4 — обёртка над `is_eligible_for_marriage`.

**Что поменяно:**
- `supported_game_version` 1.4.*, своё имя и id `bag.auto_marry`.
- `is_ai = no` первым в восьми on_action игрока (`PATCHES`): ИИ больше не
  считает свой двор ради событий только для игрока. Браки ИИ не тронуты.
- BOM в семи файлах, где автор его не поставил.
- Русский (у автора в `russian/` лежал английский), термины игры.

**Династические браки с другими странами (+beta4, его просьба 10-06).**
Автоматика игры женит только с союзниками, ленниками и списком целей и тратит
дипломатов на мнение; брак со своей знатью (+beta2) он отверг.
Теперь `auto_marry_royal.1` (скрытое, раз в месяц, файлы в `own/`) берёт одного
неженатого члена правящей семьи, годного для династического брака (19+,
женщины до 30 — пределы ИИ игры), и ищет пару того же рода в правящей семье
другой страны: сначала той же веры с `has_potential_royal_marriage`, потом той
же веры, потом любой. Проверки пары — игровые
(`character_can_marry_recipient_trigger`, не близкий родственник). Без
дипломатов и согласия. Включено по умолчанию, переключатель в меню настроек
(`auto_marry_royal_off`); напоминания автора — только когда выключено.

**Брачный возраст по сословиям (+beta5, его просьба 10-06).** Его брат 16 лет
не женился: порог был 19. Теперь пункт «Брачный возраст по сословиям» в меню
настроек (`auto_marry_age.1`): 16–22 лет отдельно для правящей семьи и каждого
сословия. Сборщик меняет «age_in_years > 18» автора на `auto_marry_age_ok_<класс>`
(`AGE_BLOCKS`, 42 места, ИИ не тронут); без переменной — 19. Не проверено.

**Зонд, не проверено:** брак пробуется `perform_diplomatic_action = { type =
royal_marriage … target/target_1 = персонажи mode = accept }` — имена аргументов
угаданы по описанию эффекта; если персонаж не женат — `marry_character`.
Событие `.2` пишет, какой путь сработал, разрешала ли игра брак и появился ли
династический брак между странами. После его загрузки лишний путь убрать.

**Не решено: `can_end` у ситуации.** 1.4 убрала `can_end` из всех 22 ситуаций
игры и завела `outcome = { name trigger }`; readme ситуаций старый и всё ещё
пишет `can_end`. ND 1.4.0 тоже держит `can_end`. Если движок его больше не
читает — в `error.log` будет строка про `noble_auto_marry_config`, а кнопка
«Убрать меню настроек» не закроет ситуацию. Не гадать: смотреть лог.
